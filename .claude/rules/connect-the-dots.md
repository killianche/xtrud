# Готовый бэк, не подключён в UI (priority 1)

## Why

Регулярная находка в аудитах xtrud: на бэке (Supabase RPC, edge functions, миграции, таблицы) **есть готовая функциональность**, но в UI она не используется — экран дёргает старый/упрощённый источник данных. Пример: RPC `search_categories` с synonym/FTS/trigram готов, но `/search.tsx` использует client-side ILIKE через `useSearchableServices`. Пользователь ищет «обои» → 0 результатов.

Это особый класс багов: TS-check проходит, тесты проходят, миграции применяются — но фича не работает с точки зрения пользователя. Происходит когда:
- бэк-фича пишется быстрее UI-интеграции и про неё забывают,
- UI-фича остаётся «временной» (client-side, hardcoded) и `// TODO: switch to RPC` не закрывается,
- два разных хука/RPC решают одну задачу и в UI попадает не тот.

## Контракт

### 1. При написании любого нового RPC / edge function / hook'а

В шапке-комментарии файла указать **где он используется в UI**. Если ещё нигде — пометить `// USAGE: not yet wired up — TODO connect to <конкретный screen>` и сразу завести TODO в `STATUS.md` § «Готовый бэк, не подключён в UI».

### 2. При замене источника данных в UI (миграция с client-side на RPC)

- Удалить старый хук, если он больше нигде не нужен.
- Если оставляешь — добавить шапку-комментарий **«USED ONLY FOR X»** с явным указанием, почему не используется новый RPC.

### 3. Перед закрытием задачи на новую бэк-фичу

Чек-лист:
- [ ] RPC / table / migration написан и применён
- [ ] Hook / data-layer создан
- [ ] **UI-экран реально дёргает hook** (не TODO, не stub)
- [ ] В preview воспроизведён сценарий который должен сработать
- [ ] STATUS.md обновлён

Если последние 2 пункта не выполнены — фича не закрыта, она в подвешенном состоянии. Внести её в STATUS.md § «Готовый бэк, не подключён в UI» с конкретным экраном куда подключать.

### 4. При аудитах

Любой агент, делающий аудит таксономии / поиска / lifecycle / любой другой фичи где есть RPC — обязан сравнить:
- что есть в БД (`pg_proc`, миграции, таблицы),
- что в `src/features/*/use-*.ts` (hooks),
- что реально импортируется и вызывается в `app/**/*.tsx`.

Несовпадения — в отчёт, в STATUS.md, в первоочередные фиксы.

## Что НЕ делать

- ❌ «UI допилим следующим спринтом» без TODO в STATUS.md и тикета.
- ❌ Дублировать функциональность: оставлять client-side ILIKE рядом с готовым FTS-RPC «на всякий случай».
- ❌ Молчать о неподключённом коде в отчёте. Если написал RPC и не подключил — указать в `⚠️ Не сделано`.
