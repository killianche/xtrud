# Снимки экранов для самопроверки

Обязательный шаг 4 из `.claude/rules/design-enforcement.md` §0. Основа — навык Anthropic `webapp-testing` (anthropics/skills, Apache 2.0): поднять приложение, дождаться загрузки, «разведка, потом действие», смотреть снимки. Всё работает только на VDS; на Mac владельца ничего не открывать.

## Как

```bash
# один раз за сессию: playwright-core вне проекта (Chromium уже лежит в ~/.cache/ms-playwright)
npm i --prefix "$SCRATCH" playwright-core@1.58
scripts/screenshots/build-web.sh "$SCRATCH/ss"            # ~2–3 мин
PLAYWRIGHT_CORE="$SCRATCH/node_modules/playwright-core/index.mjs" \
  node scripts/screenshots/shot.mjs "$SCRATCH/ss/web-dist" "$SCRATCH/ss/shots" /find,/specialists \
  --click "Ремонт и отделка" --click "Двери" --wheel 500
```

Снимки — `<маршрут>-light.png` и `-dark.png`; смотреть Read'ом, при сомнении обрезать и увеличить. Клики — по видимому тексту по порядку; `--wheel` прокручивает перед снимком (проверка размытия под заголовком).

## Что снимок доказывает, а что нет

- **Доказывает:** раскладку, отступы, иерархию, тексты, порядок, пустые/ошибочные состояния, реальные данные гостя (API читается через прокси в скрипте).
- **Не доказывает:** Liquid Glass, блюр, SF Symbols, нижнее меню iOS (в вебе оно сверху и перекрывает верх экрана), Dynamic Type, VoiceOver, свайпы пейджера. Это — только iPhone; в отчёте `UNKNOWN`.
- Вошедший пользователь не снимается (нет сессии) — «Мои задания» и экран своего задания смотреть по коду и на устройстве.

## Ловушки

- **Скрипт сборки пишет в папку из аргумента.** Относительный путь от другой папки однажды создал `web-dist/` в корне проекта — передавай абсолютный путь в scratchpad.
- **`npx expo export --clear` молча выходит, ничего не собрав.** Без `--clear`; `EXPO_PUBLIC_*` подставляются при сборке, при смене адреса API — удалить кэш Metro вручную.
- **`public/index.html` — статический лендинг**, он подменяет `index.html` приложения; скрипт делает `app.html` с бандлом и отдаёт его на любые маршруты.
- **API отвечает только своему домену (CORS).** Скрипт проксирует GET и `/rpc/` через Node; запись, `client_errors` и события не уходят никогда.
- **Веб-обёртка NativeTabs даёт контейнерам нулевую высоту** — скрипт растягивает их перед снимком. Пустой белый снимок — сначала смотри `PAGEERROR` в выводе.
- **Нативный модуль без веб-реализации ломает сборку** («Importing native-only module … on web»): нужен `*.web.tsx` рядом (пример — `SegmentPager.web.tsx`). Так же был сломан `expo-notifications` (`use-notification-tap.ts`).
- **Цвет из `useThemeColor` в вебе — CSS-переменная**, а не хекс: прозрачность к нему не приписать, а подписи `FilterChip` в тёмной теме веба тёмные. На iOS там хекс — проверять на устройстве, не «чинить» по вебу.
