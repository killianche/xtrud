## Новые правила и решения
- **Срок заказа `by_date`** — enum `order_urgency` расширен значением `by_date`; точная дата в `orders.preferred_date`. Хелпер `formatOrderTiming(urgency, preferredDate)` — единый показ срока. Миграции 0115, 0116.
- **Веб-выбор файла: флаг `changeStarted`** — focus-fallback в `pickImageWeb`/`pickMultipleImagesWeb` считает отменой только если выбор не начался. Иначе большое фото (медленный декод >500мс) терялось → заказ/аватар без фото. Это объясняло 0 файлов в bucket'ах `order-photos` и `avatars`.
- **Адаптивный фавикон через build-патч** — Expo static-render выкидывает кастомный `rel="icon"` из `+html.tsx`, поэтому SVG-ссылка инжектится в `index.html` в `scripts/build-web-local.mjs` (где уже патчатся meta-теги). Файл — `public/favicon.svg` (Expo копирует `public/` в корень).

## Новые компоненты / паттерны
- `OrderDateSheet` (`src/features/orders/`) — кросс-платформенный календарь выбора даты (чистый RN, без сторонних библиотек, обе темы). Когда: выбор «К дате» в форме заказа.
- `ReportReviewSheet` (`src/features/reviews/`) — окно жалобы на отзыв (причина + комментарий → `useCreateReport` target_type=review). Когда: мастер обжалует свой отзыв.
- `SelectedMark` (в `PickerSheet` и `AvailabilitySwitcher`) — круглый индикатор «выбрано» (bg-primary + Check в on-primary). Единый визуальный язык выбора.
- **Паттерн навбара редактирования** — «Отмена / Заголовок / Сохранить» сверху, Save disabled-until-dirty, accent когда активен. Применён в edit-client и edit-master.

## Anti-patterns обнаруженные в сессии
- **Веб `<input type=file>` + focus-fallback по таймеру** — нельзя «отменять» выбор по возврату фокуса без проверки, начался ли change. Большие файлы теряются. Правильно: флаг `changeStarted`.
- **`<link rel="icon">` в `+html.tsx`** — Expo static-render его выкидывает. Кастомные иконки/мета — через build-патч `index.html`.
- **Inline-hex в JSX** (звёзды отзывов `#f59e0b`/`#e5e7eb`) — заменено на токены `tc.warning`/`tc["muted-soft"]` (§B).
