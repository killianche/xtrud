## Курс

Продукт — нативное iOS-приложение: заказчик публикует задание, исполнители
откликаются. Android заморожен до завершения iOS. Web-сборка приложения удалена,
осталась только статика, обязательная для App Store. Отдельно строится
**веб-админка** для владельца. Backend переезжает на Beget.

Референсы, заданные владельцем: YouDo (Россия) и TaskRabbit (США).

- ⏸ **Версия `@sentry/react-native` для SDK 57.** Expo пинит `~7.11.0`, работы

### Найдено при разборе приватности — требует решения

- ⏸ **Политика заявляет сбор паспорта, которого нет.** `app/legal/privacy.tsx`
  в трёх местах обещает верификацию по паспорту, но кода, который его
  загружает, в приложении нет вовсе. Либо убрать абзац, либо доделать фичу.
  Ревьюер App Store читает эту политику.
- ⏸ **Все фото пользователей идут через сторонний CDN `images.weserv.nl`**
  (`src/lib/image-cdn.ts:29`, 9 файлов): аватары, портфолио, фото заданий. Он
  получает IP устройства и URL каждого просматриваемого фото, и **в политике не
  назван**. То же меньшим объёмом — `api.iconify.design` и `flagcdn.com`,
  причём последний на экране входа, то есть до любого согласия.
- ⏸ **Бакет `order-photos` создан публичным** (`0100_order_photos.sql:33`).
  Фото заданий — интерьер жилья, документы, повреждения — читаются анонимно по
  URL. Для аватара это оправдано, для фото задания нет.
- [ ] **Sentry в production фактически выключен:** `EXPO_PUBLIC_SENTRY_DSN` не
      задан ни в `eas.json`, ни в окружении. Крэши сейчас пишутся только в
      `client_errors`. Проверить `eas secret:list`, когда будет доступ.
