## ⏸ Ждут решения владельца

Работа по остальным пунктам идёт, но здесь выбор не мой.

- ⏸ **Приватный номер входа в `get_master_phone`.** RPC при отсутствии рабочего
  номера отдаёт `users_private.phone` — личный номер, по которому человек
  входит — любому авторизованному. Чинить сразу вместе с блокировкой или
  отдельной задачей? Починка меняет поведение опубликованного 1.0.1.
  Рекомендация: сразу, мы всё равно трогаем эту функцию.
- ⏸ **Минимум iOS 15.1 → 16.4.** Expo SDK 56+ поднимает планку; пользователи на
  iOS 15 молча теряют возможность обновляться. Долю аудитории видно только в
  App Store Connect.
- ⏸ **Версия `@sentry/react-native` для SDK 57.** Expo пинит `~7.11.0`, работы
  Sentry по SDK 57 велись в ветке `8.x`. Публичной таблицы совместимости нет.
  Решить до апгрейда, иначе `expo install --fix` молча поставит старую версию.
- ⏸ **Swap в `/etc/fstab`.** 4 GiB подключены вручную; без записи в fstab после
  перезагрузки сервера сборки iOS падают по OOM.
- ⏸ **Dormant-контракты (4 файла, 476 строк).** `universal-publish-contract.ts`,
  `universal-feed-cursor.ts`, `use-search-analytics.ts`, `outcome-store.ts`
  достижимы только из своих тестов. Заморозка под universal-активацию или
  отменённая ветка?
