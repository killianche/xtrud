# archive/

Историческая часть проекта. **Не источник истины.**

По `docs/AGENT_WORKFLOW.md` §1 всё здесь имеет приоритет 5: это история, пока
утверждение не подтверждено кодом или актуальным каноническим документом.
Агент не должен читать этот каталог ради контекста задачи — только за
конкретной исторической справкой, когда её явно попросили.

| Каталог | Что внутри |
|---|---|
| `sessions/` | Отчёты рабочих сессий, май–август 2026 |
| `audits/` | Аудиты мая 2026 |
| `launch/` | Планы и чек-листы подготовки к запуску |
| `research/` | Исследования конкурентов, рынка и внутренние аудиты кода |
| `rpi/` | Проработка верификации мастера по паспорту (не реализована) |
| `legacy/` | Прежние дизайн-системы: Cal.com, ранний DESIGN_SYSTEM |
| `vercel-design.md` | Сырой вывод `npx getdesign@latest add vercel`; актуальное — в `DESIGN.md` |

Актуальные источники перечислены в [`AGENTS.md`](../AGENTS.md).
