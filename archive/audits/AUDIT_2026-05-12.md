## TL;DR

Шесть параллельных аудитов прошли по всему текущему UI продукта (Expo SDK 54 + RN 0.81, light + dark, 23 экрана). **Найдено 113 проблем: 33 🔴 критичных, 47 🟡 важных, 33 🟢 для полировки.** Все рекомендации привязаны к 4 главным функциональным референсам (Profi.ru / Яндекс.Услуги / TaskRabbit / Thumbtack) + к Lazyweb-скриншотам (40+ URL-ов суммарно) и проходят 6 дизайн-принципов из `PRODUCT_CONTEXT.md`.

**Три системных корня объясняют половину находок:**

1. **Тёмная тема сломана не из-за DESIGN.md, а из-за компонентов.** Палитра dark уже определена в `src/lib/colors.ts` (полный экспорт `darkColors`), но 40+ мест в коде хардкодят hex прямо в `color={...}` Lucide-иконок и `placeholderTextColor`. Решается одним рефакторингом «подключить через `useThemeColor` хук».
2. **Web — это растянутое mobile.** Нигде в коде нет `Platform.OS === "web"` для структурного выбора layout (top-nav vs bottom-tabs, split vs stacked). Theme-toggle на web не виден. Max-width на десктопе нет. Это отдельная большая работа на Sprint 25.
3. **Принцип №4 «скорость» не реализован:** 0 skeleton-loaders, 46 `ActivityIndicator`. Принцип №2 «фото — главный визуальный нерв» тоже: hero-фотографий мастеров нет, портфолио upload без crop/ratio, аватарки 40–96px вместо больших блоков.

**Что в проекте отлично и НЕ трогать:** `colors.ts` (WCAG-комментированная палитра), `+html.tsx` theme-guard inline-скрипт, AuthGate 3-state router, OutcomeTrackingModal архитектура, Inter через `@expo-google-fonts`, корректная разбивка orders state-machine на хуки/RPC, accessibilityLabel в ключевых местах профиля.

## ТОП-10 🔴 критичных через все группы (must-fix перед публичным запуском)

1. **Карточка мастера (`master/[id].tsx`) — не Thumbtack pro detail.** Hero — круглая аватарка 96px, нет hero-фото, нет sticky CTA «Написать в чат», портфолио — пятый блок вниз. Это **главный conversion-экран продукта** и он сейчас визуально слабый. → `discovery.md` 🔴#1, #3.
2. **Главная (`tabs/index.tsx`) — плоская сетка категорий без поиска, без top-recommended-мастеров, без городского селектора.** Противоречит TaskRabbit Browse + Profi.ru каталогу. → `discovery.md` 🔴#2.
3. **OrderStatusBadge отсутствует в UI.** State-machine на 6 статусов реализована в БД (`docs/order-states.md`), но в карточках/деталях статус виден только через косвенные тексты. Клиент и мастер не понимают, на каком шаге заказ. → `orders.md` 🔴#1.
4. **Кнопки «Отменить заказ» нет.** State-machine разрешает `open/in_progress → cancelled` (T2/T6), RLS готова, UI-выхода нет. → `orders.md` 🔴#2.
5. **Чат теряет контекст заказа.** payload `useMyChats` уже содержит `order.status`, `avatar_url` — UI игнорирует. Принцип №6 «функциональность» нарушен. → `chats.md` 🔴#1.
6. **Шаблонов быстрых ответов в чате нет.** Самый высокий ROI для marketplace-чата (Thumbtack, Airbnb). → `chats.md` 🔴#2.
7. **Onboarding мастера ломанный:** нет шага «фото профиля» и шаг «категории» не встроен в визард. Мастер выходит в табы без фото (нарушение принципа №2) и без категорий → ноль конверсий из ленты. → `auth-onboarding.md` 🔴#3.
8. **`verify.tsx` — OTP одним TextInput.** Стандарт 2026 года — 6 отдельных боксов с auto-paste из SMS. → `auth-onboarding.md` 🔴#2. Disclaimer «Sprint 1: код принимается любой» виден пользователю в `phone.tsx` — убивает доверие. → `auth-onboarding.md` 🔴#1.
9. **Dark theme не работает на 40+ точек.** 26 файлов с `color="#0a0a0a"` на Lucide-иконках, 16 точек `placeholderTextColor="#71717a"`, `tabBarBadgeStyle` хардкод `#ef4444`. Палитра в `colors.ts` уже есть, нужно подключить через `useThemeColor`. → `cross-cutting.md` 🔴 B1, B2, B3.
10. **Skeleton-loaders отсутствуют (46× `ActivityIndicator`).** Принцип №4 «скорость» не реализован. Open масштабируется белым экраном → spinner → контент. → `cross-cutting.md` 🔴 C1.

- Sidebar+main для chats на десктопе отсутствует (cross-cutting A2).

## Дисклеймеры аудита (для честности)

1. **6-й (cross-cutting) агент упал из-за лимита usage** — выполнен в main session с 3 Lazyweb-запросами (вместо 5+). Скомпенсировано глубоким `grep` по коду (40+ хардкод-точек цвета перечислены пофайлово) + ссылками на 5 готовых отчётов.
2. **Все 6 отчётов — static-code review.** Реально работающий билд для runtime-проверки (Dynamic Type, dark-mode рендеринг плашек, реальный wrap pill-row, фактическое поведение на iPhone SE2) не запускался — это указано как гипотезы в отдельных находках.
3. **Прямых Thumbtack-скриншотов в Lazyweb мало** — для модели «hero+sticky CTA+trust» дополнительно использованы Airbnb listing detail, Craigslist listing, Alibaba supplier как функциональные эквиваленты. Это разрешено в `BRIEF.md`: цитата Thumbtack из текста `PRODUCT_CONTEXT.md` валидна.
4. **Web-вариант** оценивался преимущественно по коду (`grep Platform.OS`, `grep md:`/`lg:`), не по фактическому развёртыванию `https://alanbani.ru/xtrud/`. Если в продакшене уже что-то отличается — отмечайте при PR.
