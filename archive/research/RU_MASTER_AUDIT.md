# Аудит master-аккаунтов: российские сервисы услуг

> **Назначение:** база для разработки полноценного master-аккаунта в xtrud (full-free маркетплейс услуг для Республики Ингушетия).
> **Дата:** 2026-05-15
> **Автор:** AI-аналитик, по open-source источникам (help-центры, vc.ru, livejournal-обзоры, Sravni, Habr).
> **Период данных:** 2024–2026, отдельные оценки 2020–2023 (отмечено в тексте).

---

## TL;DR — 7 главных выводов

1. **Все четыре российских лидера (Профи.ру, YouDo, Яндекс Услуги, Авито Услуги) монетизируются на исполнителях, а не на клиентах.** Монетизация бывает трёх форм: (а) платный отклик «pay-per-bid» (Профи.ру, YouDo), (б) комиссия с выполненного заказа (Профи.ру для repeat-категорий — репетиторы / психологи / автоинструкторы / спорт-тренеры), (в) платное размещение / pay-per-contact (Авито Услуги, частично Яндекс). Полный free-tier — редкость; обычно free даёт первые N откликов / первые 3 объявления / лимит в день, дальше платно.

2. **Иерархия категорий — везде 2–3 уровня.** Эталон у Яндекс Услуг: **19 категорий L1 → 198 подкатегорий L2 → опциональная кастомная услуга L3** (исполнитель сам формулирует названия). У Профи.ру — около 900 «видов услуг» в плоской выдаче, но сгруппированы в 5–7 главных направлений (репетиторы / ремонт / красота / фриланс / бухгалтеры-юристы и т.д.). У Авито — каталог «Услуги» с 12+ L1 (автосервис, ремонт, IT, красота, перевозки, обучение и т.д.) и десятками L2. **Bottom-sheet с поиском** + **ручной выбор одной L2** — стандарт. Множественные категории через **отдельные «карточки услуг»**, не через мультивыбор в одном поле.

3. **Регистрация — короткий wizard (3–5 шагов): телефон → СМС → ФИО → город → категория.** Паспорт и большая анкета — **отложены в фоновую задачу** «дозаполнить профиль». Никто не требует пройти все 20 полей сразу — это убивает конверсию. Типичный путь: за 2 минуты получить статус «начинающий специалист» → дальше 1–2 дня модерации после загрузки паспорта → бейдж «Документы проверены» (или «Самозанятый», «Реквизиты проверены»).

4. **Цена в карточке — обязательное поле, и почти везде это «прайс-лист» из услуг с цифрами, а не «договорная».** Профи.ру строит на этом фишку — клиенту в выдаче показывают цену, средний рейтинг и фото. Яндекс — фиксированная цена или диапазон («от 1 000 ₽» / «1000–2500 ₽»). Авито — одна цена за объявление + текст. YouDo — клиент сам ставит бюджет, исполнитель его принимает или предлагает другой. **«Договорная»/«по запросу» — допускается, но снижает конверсию.**

5. **«Заказ → отклик → чат → встреча → отзыв» — единая воронка у всех.** Различия — в защите от увода в Telegram. **Профи.ру и YouDo агрессивно блокируют контакты до оплаты комиссии/отклика** (роботы сканируют чаты, шифровать номер на фото запрещено — алгоритм визуального распознавания вычисляет). **Яндекс / Авито — мягче,** контакты открываются по кнопке, но платформа отслеживает обмен.

6. **Бейджи и trust — три уровня везде:** (1) телефон подтверждён (по СМС автоматически), (2) **паспорт / Госуслуги** (даёт бейдж «Документы проверены» или «Паспорт подтверждён»), (3) **самозанятый / ИП через Госуслуги** (даёт бейдж «Самозанятый» — конверсия в выбор +20–40%). Дополнительно: рейтинг 5★ из отзывов, число выполненных заказов, бейджи «Топ», «Очень хвалят», «Проверен» (выдаются по непрозрачным критериям). **Сертификаты и дипломы — опционально**, повышают доверие, но не обязательны (кроме Профи.ру для медицинских и репетиторских категорий).

7. **Бесплатный тариф — это «попробовать», а не «работать».** На YouDo и Профи.ру **без покупки откликов невозможно вести бизнес**: 5–10 «пробных» бесплатных откликов → дальше платно. На Яндекс Услугах **бесплатный тариф жизнеспособен** (7 откликов в день, безлимит размещения услуг), но без продвижения профиль не виден без органики Yandex Search. На Авито **3 бесплатных объявления + базовый Pro-кабинет**, дальше за каждое от 17–600 ₽ (зависит от категории/региона) или подписка от 3 000 ₽/мес.

**Главный инсайт для xtrud:** наш USP «полностью бесплатно для мастеров» бьёт прямо в боль 80% российских специалистов — устали платить за лиды, которые не конвертируются. Но **этого мало**: чтобы был спрос на платформе, нужен качественный UX (3-уровневая таксономия, прайс-лист, бейджи доверия, нормальный чат) на уровне Профи.ру/Яндекса. Без этого «бесплатно» = «никому не нужно».

## Платформа 1: Яндекс Услуги (Яндекс Исполнители)

> **Год запуска:** 2018. **Аудитория:** покрывает всю РФ через каталог + поиск Яндекса. **Web URL:** uslugi.yandex.ru. **App:** «Услуги Про» (отдельное приложение для исполнителей на iOS/Android).

### Регистрация и онбординг

**Wizard — 4 обязательных шага** (источник: ilyachalov.livejournal.com/335768.html, kokoc.com/blog/yandex-uslugi/):

1. **Авторизация через Яндекс ID** (с привязанным телефоном). Если телефона нет — СМС-код для подтверждения.
2. **«Стать исполнителем»** в правом верхнем углу главной (uslugi.yandex.ru).
3. **Имя + фамилия** (реальные, будут сверены с паспортом) + город. Опциональное «согласие на распространение ПД».
4. **Выбор категории** (обязательно — одна L1 + одна L2 как минимум для публикации).

**После публикации профиля** — отдельные опциональные шаги (можно пропустить):
- Загрузка фото профиля.
- Проверка паспорта (через QR-код в приложении / загрузка скана).
- Заполнение разделов «О себе», образование, контакты.

**Self-employed/ИП vs физлицо:** на старте выбирается «Частный специалист» или «Организация». Для организаций требуется ОГРН/ОГРНИП. Самозанятость отдельно не выделяется в флоу регистрации, но при загрузке справки появляется бейдж.

**Модерация:** до 2 рабочих дней. При **любом изменении** профиль временно скрывается с поиска и проходит повторную модерацию (10 минут — 2 дня). Это **критическая UX-проблема**: исполнитель боится менять цены/тексты, потому что 2 дня без видимости.

**Скриншоты UI** (по описаниям из livejournal-обзоров): белый фон в стиле Яндекса, шаги горизонтально, форма из 3–5 input-полей на каждом шаге. Всё в одной длинной странице регистрации.

### Заполнение профиля

Профиль исполнителя имеет **«внутренний»** вид (то, что видит сам мастер в кабинете) и **«внешний»** (для клиентов). 3 основных блока:

1. **Личные данные** — имя, фото, город, статус онлайн, способы связи.
2. **Специализация и услуги** — карточки услуг с описанием, ценой, длительностью, местом.
3. **Отзывы клиентов** — список + средний рейтинг.

Боковая панель: рейтинг (число 4.X), кнопка «оставить отзыв», бейдж «Паспорт проверен», карта местоположения.

**Поля:**
- Имя/фамилия — обязательно.
- Фото — обязательно для попадания в топ выдачи (требование модерации: лицо по центру, без масок, открытые глаза).
- Описание «О себе» — рекомендуется до ~2600 символов (3800 уже отклонят).
- Видео-самопрезентация / кейсы «до-после» — опционально, повышает CTR.
- Образование, сертификаты — опционально, отдельный раздел.
- Соцсети, YouTube — можно, ссылки разрешены.
- Адреса (домашняя точка + регионы выезда) — для radius-фильтрации.

### Категории услуг (таксономия)

**19 категорий L1** (например: «Репетиторы и обучение», «Ремонт и строительство», «Красота и здоровье»...), каждая раскрывается в **подкатегории L2 — у автора livejournal-обзора было 198 вариантов в одной L1**, что даёт примерно ~3700+ L2 по всей платформе.

**UX выбора (на регистрации):** список с поиском по названию. Выбирается одна L2. После — можно «создать свою услугу L3» (свободный текст: «Установка унитаза Roca из импортных комплектующих»).

**Лимит:** не указан явный, но несколько L2 возможны через создание нескольких **карточек услуг**, каждая в своей категории.

### Ценообразование

В карточке услуги (источник: yandex.ru/support/uslugi-masters/ru/uslugi/service-offer-guide):

- **Описание услуги** (обязательно).
- **Цена** — фиксированная (1500 ₽), диапазон («от 1000 ₽», «1000–2500 ₽»), либо «договорная».
- **Фото** работ.
- **Сроки и показатели качества** (например: «1 час», «выезд в течение дня»).
- **Предпочтительные дни/время работы** — для синхронизации с календарём клиента.
- **Удалённые услуги** — отдельный флаг.

**Запрещено в описании:** email-адреса (только в спец-поле профиля), прямые гиперссылки (можно написать название без href).

### Получение и работа с заказами

**Две модели одновременно:**

1. **Каталог + прямой контакт.** Клиент находит профиль через поиск Яндекса/каталог, нажимает «Позвонить» или «Написать» — открывается чат / звонок. **Без отклика, без оплаты.**
2. **Биржа заказов («Поиск заказов» в кабинете).** Клиенты создают «задание», исполнители видят список и могут откликнуться.

**Лимит откликов в бесплатном тарифе:** **до 7 в день** (источник: blog.promopult.ru). Безлимит — **199 ₽/неделя** подписка (это очень дёшево по сравнению с YouDo).

**Карточка лида** содержит: бюджет клиента, описание задачи, локация (район/город), фото от клиента (если приложил), срочность, контакт открывается **после отклика**.

### Подписка и продвижение

- **Бесплатно:** размещение профиля, неограниченное число услуг, до 7 откликов/день.
- **Безлимит откликов:** ~199 ₽/неделя (≈800 ₽/мес).
- **Платное продвижение через Яндекс Директ:** оплата за клики, минимум 1000 ₽/день бюджет; для физлиц — от 300 ₽ за внутреннее продвижение.
- **«Базовый» vs «Профессиональный»** — два тарифа продвижения на самой платформе.

### Безопасность и trust

- **Паспорт-проверка** (QR из приложения / загрузка) — даёт бейдж «Паспорт подтверждён».
- **ОГРН/ОГРНИП** для организаций — бейдж «Документы проверены».
- **Модерация** каждого изменения профиля (2 дня — критичная UX-проблема).
- **Жалобы и блокировки** — известны кейсы накрутки рейтинга → автоматическое снижение/бан.
- **Отзывы только от верифицированных клиентов** (после факта заказа через платформу).

### Уникальное

- **Глубокая интеграция с экосистемой Яндекса** — поиск, Карты (профиль показывается на карте), YCLIENTS-интеграция для онлайн-записи.
- **Самый дешёвый безлимит** среди конкурентов (199 ₽/нед).
- **Видео-самопрезентация** прямо в карточке услуги.
- **Отдельное приложение «Услуги Про»** для мастеров.

## Платформа 2: Профи.ру (Profi.ru)

> **Год основания:** 2005 (как «Ваш репетитор»). **Аудитория:** 15+ млн клиентов, 3+ млн специалистов, 900+ типов услуг, ~1.7 млн активных мастеров. **Web:** profi.ru. **App:** «Профи.ру — услуги и мастера» (iOS/Android).

### Регистрация и онбординг

**Wizard:** телефон → СМС-код → пароль/email/имя/специализация → загрузка фото (источник: webereg.ru/servisy/profiru, life-practic.ru).

**Шагов меньше, чем у Яндекса** (3–4), но **анкета сильно больше**, и нужна для попадания в выдачу. Без качественной анкеты — нулевая конверсия.

**Верификация паспорта** — обязательна для большинства категорий (особенно репетиторы, психологи, медицина). Без бейджа «Паспорт проверен» клиенты выбирают редко.

**Сертификация (отдельный продукт Профи.ру для мастеров):** проверка документов + онлайн-экзамен → бейдж «Сертифицирован Профи». Дорогая, но даёт +30% к конверсии для репетиторов.

### Заполнение профиля

**Анкета содержит:**
- Имя, фото профиля.
- **Подробное описание «О себе»** (краткая + длинная версия) — рекомендация: образование, курсы, стаж, инструменты.
- **Прайс-лист услуг** с конкретными ценами (каждая строка отдельно).
- **Портфолио** — фото выполненных работ (рекомендуется 10+).
- **Дипломы и сертификаты** (фото с возможностью верификации).
- **Видео-визитка** — фрагмент урока репетитора, видео ремонта, выступление ведущего. Сильно повышает конверсию.
- **Отзывы клиентов** (приходят автоматически после заказа).
- **Геолокация** — район/станция метро + радиус выезда.

**Ограничения модерации:**
- Дипломы о профпереподготовке без основного высшего — не принимаются.
- Сертификаты дистанционных курсов с самообучением — не принимаются.
- В чате нельзя писать номер телефона — даже словами/шифром: визуальное распознавание ловит на фото.

### Категории услуг (таксономия)

**~900 видов услуг** организованы в крупные блоки:
- Репетиторы (1923 «предмета»): английский, математика, русский, начальная школа, музыка, ...
- Мастера по ремонту (1993 услуги): сантехники, электрики, плиточники, штукатуры, под ключ.
- Мастера красоты (1992 услуги): макияж, маникюр, причёски, эпиляция, стилисты.
- Фрилансеры (1118): дизайнеры, маркетологи, сисадмины, копирайтеры.
- Бухгалтеры и юристы.
- Доставка, грузоперевозки, уборка, компьютерная помощь, фото-видео-аудио, программирование, ремонт бытовой техники, дизайн, авторемонт, обучение, праздники.

**Иерархия:** условно 2–3 уровня (Категория → Подкатегория → конкретная услуга), но **внутри каждой подкатегории длинный плоский список** на 100+ услуг. UX выбора — поиск + чек-боксы / список с поиском.

**Пример 3 уровней:**
- L1: Ремонт и строительство → L2: Сантехника → L3: «Установка унитаза», «Замена смесителя», «Прочистка засора».

### Ценообразование

Каждая строка прайс-листа — это отдельная услуга **с фиксированной ценой ИЛИ диапазоном «от X ₽»**. UX редактирования: список с inline-edit или bottom-sheet на каждую строку.

В выдаче клиент видит: «Иванов Иван — Установка унитаза, от 1500 ₽, ★4.9, 87 отзывов».

### Получение заказов и тарифы (САМОЕ ВАЖНОЕ)

**Две модели:**

1. **«Отклик»** (доступен всем):
   - Стоимость отклика — **1–2500 ₽**, в среднем 30–250 ₽ (зависит от бюджета, услуги, района).
   - Деньги списываются **сразу при отправке отклика**.
   - Возврат — только если клиент не открыл отклик за 5 дней И исполнитель не открывал контакты.
   - **5–20 откликов в день максимум** (зависит от рейтинга).

2. **«Комиссия»** (только для репетиторов, психологов, автоинструкторов, спорт-тренеров):
   - Доступен после 10 платных откликов (порог входа).
   - Платишь **только за выполненные заказы** с полученной оплатой.
   - Размер — % от типа заказа (точные числа Профи не публикует).
   - Списывается через 14 дней после обмена контактами.
   - Возврат: 1 час (сам оплатил) / 3 месяца (списалось автоматически).

**Антифрод:** алгоритм блокирует попытки увода клиента в Telegram (роботы сканируют чаты + визуальное распознавание на фото).

### Аналитика и инструменты

- **Кабинет специалиста:** просмотры профиля, число откликов, конверсия в заказ, рейтинг по дням.
- **Шаблоны откликов** (плата всё равно, но быстрее писать).
- **Геофильтр** — управление радиусом выезда.
- **Бейджи:** «Паспорт проверен», «Очень хвалят» (по непрозрачным критериям, недоступен многим топ-мастерам).

### Уникальное

- **Самая глубокая верификация квалификации** — Сертификация с экзаменом (отдельный продукт).
- **Прайс-лист как обязательная фича** — конкретные цены за каждую строку, не «договорная».
- **Видео-визитка** прямо в карточке.
- Самый старый сервис на рынке (с 2005), доминирует в категории репетиторов.

### Anti-patterns

- **Бесплатно — невозможно работать.** 10 «пробных» откликов → дальше плати.
- **Цены откликов часто завышены** (отзывы: «отдал 400 ₽, клиент даже не открыл»).
- **Шантаж модерацией:** при изменении профиля — пересмодерация.
- **Жалобы на «фейковые заказы» от админов** для прогрева баланса (irecommend.ru, dtf.ru) — спорно, но репутационный риск.

## Платформа 3: YouDo (Юду)

> **Запуск:** 2012. **Аудитория:** 5+ млн исполнителей, 15+ млн заказчиков. **Web:** youdo.com. **App:** «YouDo: работа, курьеры, уборка» (iOS/Android). **Модель:** биржа заданий (бид-аукцион).

### Регистрация и онбординг

**3 шага верификации** (источник: help.youdo.com, lifehacker.ru, mamina-kariera.ru):

1. **Личные данные:** ФИО, дата рождения, город, фотография.
2. **Подтверждение телефона** — 5-значный СМС-код.
3. **Выбор категорий** (одна или несколько из 16 верхних).

**Возрастной порог:** 18+. Без исключений.

**Селфи-верификация** в спорных случаях (если регистрация подозрительная). Использование «не своих» контактов/фото = бан.

**После регистрации** — статус «Исполнитель», push-уведомление + инструкция «как начать работать».

### Заполнение профиля

**Источник:** help.youdo.com/ru/articles/2596843.

- **Фото профиля.**
- **Описание** — преимущества для клиента, условия работы, опыт.
- **Образование и стаж работы.**
- **Портфолио** — рекомендуется 10+ фото/видео. **Статистика YouDo:** исполнители с богатым портфолио выбираются на 30% чаще.
- **Подтверждение** телефона, email, соцсетей (галочки).
- **Статистика в карточке:** число выполненных заказов, средний рейтинг.

### Категории услуг (таксономия)

**16 верхних категорий:**
1. Курьерские услуги (доставка, продукты, еда).
2. Ремонт и строительство (от замены розетки до ремонта под ключ).
3. Грузоперевозки.
4. Уборка и помощь по хозяйству.
5. Виртуальный помощник.
6. Компьютерная помощь.
7. Мероприятия и промо.
8. Дизайн.
9. Веб-разработка.
10. Фото и видео.
11. Установка и ремонт техники.
12. Красота и здоровье.
13. Ремонт цифровой техники.
14. Юридическая помощь.
15. Репетиторы и обучение.
16. Ремонт транспорта.

Каждая категория делится на **подкатегории L2** (Курьерские → Срочный курьер / Доставка еды / Доставка документов и т.д.).

### Ценообразование (модель отличается!)

**На YouDo цену ставит КЛИЕНТ, не исполнитель.** Клиент пишет: «Помыть окна за 2000 ₽», и исполнители откликаются: «согласен», «давайте за 2500», «давайте за 1800».

В **профиле** исполнителя нет прайс-листа в обычном смысле — есть **примеры выполненных заказов с ценами** (накапливаются автоматически).

### Получение заказов и тарифы (САМОЕ ВАЖНОЕ)

**Все заказы через бид-модель:**

1. Клиент создаёт задание → пуш всем подходящим исполнителям.
2. Исполнители «откликаются» (нажимают кнопку, иногда дописывают предложение).
3. **Отклик платный.** В среднем: 39 ₽ (категория Ремонт, 2020 — данные old) → 45–70 ₽ (типичный single-bid) → до 130–400 ₽ при «постоплате», когда клиент запрашивает контакты.
4. Клиент выбирает одного → они переходят в чат → договариваются.
5. После выполнения — отзыв, оплата напрямую (или через YouDo Safe — отдельная фича).

**Тарифы 2024–2025:**

- **Базовый пакет** (фиксированное число откликов):
  - 20 / 50 / 100 откликов на 30 дней.
  - Цена зависит от категории и города (от ~20 ₽/отклик в дешёвых до 200+ ₽).
- **Безлимитный пакет** (на категорию):
  - 15 / 30 / 90 дней.
  - Цена считается **за сутки** и зависит от категории и города.
  - **Примеры:** Дизайн — ~8600 ₽ за 30 дней (≈287 ₽/день). Грузоперевозки — ~1000+ ₽/день. Минимум для дешёвых категорий — от 150 ₽/день.

**Отклики с постоплатой:** клиент сначала запрашивает контакты, и только тогда списывается (но дороже).

**Комиссия YouDo:** 3–5% с суммы выполненного заказа (если оплата через платформу).

### Самозанятый интеграция

YouDo обрабатывает налоги для самозанятых: генерирует чеки, удерживает 4–6% налог автоматически. Это удобство — реальный плюс.

### Аналитика

- **Статистика заказов** в кабинете.
- **Рейтинг и отзывы** — динамика.
- **Просмотры профиля.**
- **Бейджи**: «Проверенный исполнитель», «Топ», специальные значки за категории.

### Безопасность

- Верификация паспорта/телефона.
- Защита от увода в мессенджеры (контакты после оплаты отклика).
- YouDo Safe — escrow-сделка с гарантией возврата.
- Жалобы → блокировка профиля.

### Уникальное

- **Бид-аукцион вместо прайс-листа** — единственный из 4 крупных.
- **Полное налоговое сопровождение для самозанятых.**
- **Категории курьерских услуг** — самая сильная вертикаль (Москва).

### Anti-patterns

- **Дорогой отклик при низкой конверсии:** отзывы массово жалуются на «потратил 1000 ₽, не получил ни одного заказа». Особенно в дизайне и юридической помощи.
- **Размытая граница «отклика» и «контакта»** — пользователю непонятно, когда списывается какая сумма.
- **Минимальный free-tier** — без покупки пакета можно сделать единичные дорогие отклики.

## Платформа 4: Авито Услуги

> **Запуск:** 2013 (внутри Avito.ru). **Аудитория:** 62.3 млн пользователей/месяц у Авито в целом. **Web:** avito.ru/all/predlozheniya_uslug. **App:** «Avito» (объединённое приложение). **Модель:** доска объявлений + профессиональные профили.

### Регистрация и онбординг

**Вход:** один аккаунт Авито на номер телефона (СМС-код). Никакого отдельного wizard «стать исполнителем» — просто создать первое объявление в категории «Услуги».

**Типы аккаунтов** (источник: okocrm.com, vc.ru/marketing/2746315):
- **Частное лицо.** Базовый аккаунт. До **2 профессиональных профилей** (с марта 2024).
- **Самозанятый.** Подтверждение через Госуслуги/T-ID/Сбер ID → бейдж «Самозанятый».
- **ИП / компания.** До 10 проф-профилей. Подтверждение реквизитов → бейдж «Реквизиты проверены».

**Профессиональный профиль** (отдельная сущность):
- Платная подписка для бизнес-функций.
- Кнопки «Написать»/«Позвонить» в карточке.
- Отдельная страница «как мини-сайт».
- Статистика: **+11% просмотров, +58% заказов** vs обычный профиль (данные Авито).

### Верификация

**С 2024 — упрощённая верификация через Госуслуги** (без приложения «Госключ»). Доступно с любого устройства.

**3 уровня бейджей:**
- **«Документы проверены»** — частное лицо с верифицированным паспортом.
- **«Самозанятый»** — через Госуслуги/Сбер ID/T-ID.
- **«Реквизиты проверены»** — компания/ИП с подтверждёнными ОГРН.

**78% пользователей предпочитают верифицированных** (статистика Авито).

**«Отчёт об исполнителе»** (новая фича 2024–2025): автоматическая проверка по открытым источникам — действительность паспорта, судебные дела, розыск, статус самозанятого. **Пока в категориях:** няни/сиделки, уход за животными, уборка.

### Заполнение профиля

- **Аватар/логотип** — фото или брендированный логотип.
- **Описание:** «несколько слов о себе» + про услуги + контакты (контакты появляются после модерации).
- **«О компании»:** как давно, какие услуги, преимущества.
- **Список услуг** = список объявлений в проф-профиле.
- **Отзывы** — собираются автоматически после сделок.
- **Рейтинг.**
- **Адрес/география.**

### Категории услуг (таксономия)

В категории «Услуги» — **12+ L1**:
- Автосервис.
- Ремонт и строительство.
- Красота и здоровье.
- Обучение, курсы.
- Бытовые услуги.
- Уход за животными.
- IT-услуги.
- Перевозки и грузчики.
- Уборка.
- Бухгалтерские, юридические.
- Праздники, мероприятия.
- ...

Каждая L1 — десятки L2. Глубина 2 уровня + ключевые слова в самом объявлении.

**UX выбора:** при создании объявления — wizard «введите название» → платформа автоматически предложит категорию → можно поправить вручную через дерево L1/L2.

### Ценообразование

В Авито логика **«одно объявление = одна услуга = одна цена»** (или диапазон в тексте).

- **Цена обязательна** в каждом объявлении.
- Возможен **расширенный прайс-лист** в описании (текстом).
- Доставка / выезд / гарантия — отдельные галочки + текст.

### Получение заказов и тарифы (САМОЕ ВАЖНОЕ)

**Три модели монетизации в Услугах:**

1. **Бесплатно:** первые 3 активных объявления.
2. **Pay-per-listing:** от 17 ₽ (дешёвые регионы) до 600+ ₽ за объявление, **на 30 дней (или 14/60 в зависимости от тарифа)**. С 4-го объявления — от 250 ₽ каждое в Москве.
3. **Pay-per-action / per-contact (только Услуги):** размещение бесплатно, **списание от 45 ₽ за каждое полученное сообщение или звонок** (зависит от категории и региона). Подключается через менеджера или поддержку.
4. **Подписка (Avito Pro):**
   - **«Базовый»** — бесплатно. Кабинет, аналитика, демо-инструменты.
   - **«Расширенный»** — 2000–3000 ₽/мес. Баннеры профиля, бонусы продвижения.
   - **«Максимальный»** — 3000–6000 ₽/мес. Брендирование, водяные знаки на фото, **скрытие конкурентов из выдачи** при поиске.
5. **Категория Услуги — подписка от 3000 ₽/мес** в Pro-тарифах (за подписку 6000 ₽ в товарной категории).

**Заказы как процесс:**

- Клиент находит объявление → **«Написать»** (внутренний чат) или **«Позвонить»** (тел напрямую).
- Чат внутренний (не Telegram).
- Договариваются вне платформы (нет встроенной escrow).
- После сделки — клиент может оставить отзыв.

### Аналитика

- **Avito Pro кабинет:** разделы «Лиды», «Статистика», «Компания», «Настройки».
- **Воронка:** просмотры → клики на объявление → контакты → заявки.
- **Анализ спроса по ключевым запросам** (только Pro): объём запросов в месяц.

### Уникальное

- **Самый большой охват** среди всех — 62 млн MAU.
- **Доска объявлений как UX** (привычный паттерн для русского пользователя из 2010-х).
- **«Скрытие конкурентов из выдачи»** на Максимальном тарифе — уникальная фича.
- **«Отчёт об исполнителе»** — глубокая trust-проверка по открытым реестрам.

### Anti-patterns

- **Объявления похожи на товары** — UX не оптимизирован под услуги.
- **Дорогая монетизация по контактам** — отзывы жалуются на платежи за «холодные» обращения.
- **Конкуренция с обычными объявлениями** в категории Услуги — снижает доверие.

## Что обычно ВКЛЮЧЕНО в бесплатном тарифе (best practices)

Это критично для xtrud — мы **полностью бесплатны**, и нам важно знать что считается «достаточным базовым набором» в РФ.

### Включено бесплатно у всех 4 крупных:

1. **Регистрация и базовый профиль.**
2. **Размещение профиля в каталоге** (с видимостью в поиске).
3. **Просмотры профиля** клиентами.
4. **Внутренний чат с клиентом** после первого контакта.
5. **Получение и хранение отзывов.**
6. **Базовая статистика** (просмотры, контакты).
7. **Подтверждение телефона.**
8. **Опциональная верификация паспорта/самозанятости** — даёт бейдж бесплатно (доп. функции — за плату).

### Урезано (платно или закрыто) в free-tier:

1. **Количество откликов на заказы.** YouDo — мизер. Профи — 10 пробных. Яндекс — 7/день. Авито — N/A (другая модель).
2. **Видимость в топе выдачи.** Без платного продвижения профиль на 5–10 странице.
3. **Скрытие конкурентов** (Авито Pro Max, Яндекс Профи).
4. **Брендированная страница / баннеры** (Avito Pro, Яндекс Pro).
5. **Аналитика по ключевым запросам** (Avito Pro).
6. **Безлимит откликов** (Яндекс — 199 ₽/нед, YouDo — пакеты от 4500 ₽/мес).
7. **Постоплата за контакты** (YouDo — премиум-модель).
8. **Профессиональная сертификация** (Профи.ру).

### **Вывод для xtrud:**

В нашем full-free мы должны как минимум давать:
- ✅ Регистрация, профиль, видимость в каталоге.
- ✅ **Безлимитные отклики и контакты** (наш main USP).
- ✅ **Внутренний чат** с клиентом (защита от увода в Telegram **не нужна**, потому что мы не зарабатываем на лидах — но желательна для UX и trust клиентов).
- ✅ **Полная аналитика** в кабинете.
- ✅ **Все бейджи доверия** (паспорт, самозанятый — через интеграцию с Госуслугами).
- ✅ **Прайс-лист услуг** с фиксацией цен (как Профи.ру + Яндекс).
- ✅ **Портфолио** (10+ фото).
- ✅ **Видео-визитка** (как Профи / Яндекс).

Что **отсутствует** (как фича) и хорошо:
- ❌ Платное продвижение в топ выдачи (нет монетизации = нет искажений).
- ❌ Брендированные страницы (если не делать enterprise-tier).
- ❌ Скрытие конкурентов.

**Замена монетизации** — наш доход не от мастеров, а от других источников (доп.услуги для клиентов, реклама смежных услуг, B2B-договоры). Это уже не предмет данного аудита.

## Best practices — что обязательно взять в xtrud

### 1. Wizard регистрации — короткий

**Эталон: Яндекс.** 4 шага, под 2 минуты до первой публикации.
- **Шаг 1.** Телефон → СМС.
- **Шаг 2.** Имя + город (опционально — район).
- **Шаг 3.** Выбор L2-категории (с поиском, bottom-sheet).
- **Шаг 4.** Готово, статус «Начинающий мастер», красный пульс «Дозаполните профиль».

**НЕ** требовать паспорт/портфолио на старте — **fail.** Это убивает конверсию.

### 2. Таксономия категорий — 3 уровня bottom-sheet с поиском

**Эталон: Яндекс + Профи.ру.** L1 → L2 → опциональная кастомная L3.
- Категорий L1 — **10 (как у нас уже есть)**.
- L2 — **64 (как у нас уже есть)**.
- L3 — **290 (наша таксономия)** — рекомендуется как опция «уточнить услугу», не обязательно.

**UX:** bottom-sheet с поиском + tree-view (раскрывающиеся L1 → L2 → L3). Не chip-row, не плоский список.

### 3. Прайс-лист как обязательная сущность

**Эталон: Профи.ру + Яндекс.** Каждая услуга = строка с ценой.
- Цена: фикс (1500 ₽) / диапазон (1000–2500 ₽) / договорная (только опционально, плохо для CTR).
- Единицы: за услугу / за час / за выезд / за м².
- UX: bottom-sheet «Добавить услугу» с инлайн-полями, единый компонент через все экраны.

### 4. Портфолио — 10+ фото

**Эталон: Профи + YouDo.** Статистика YouDo: с богатым портфолио — на 30% чаще выбирают.
- Min рекомендация: **10 фото**.
- Поддержка видео-визитки (как у Профи).
- Image-picker → Supabase Storage → CDN.

### 5. Бейджи доверия — 3 уровня

1. **Телефон подтверждён** (автоматически по СМС).
2. **Паспорт / Госуслуги** — даёт бейдж «Документы проверены».
3. **Самозанятый** — отдельный бейдж (через интеграцию с ФНС / Госуслугами).

Дополнительно: **«Топ-мастер»** (по рейтингу — после N выполненных заказов), **«Хорошие отзывы»** (90%+ положительных).

### 6. Внутренний чат + анти-увод (опционально)

Клиенту нужна защита: чат с фото, шаблонами ответов, push-уведомлениями. Анти-увод (запрет писать номер) — **не обязательно** для нас (нет монетизации лидов), но улучшает trust клиентов.

### 7. Геолокация и radius

**Эталон: Avito + Яндекс.** Адрес мастера + радиус выезда. Возможность отметить «выезжаю по всей республике».

### 8. Видео-самопрезентация

**Эталон: Профи.ру.** Короткое видео в карточке. Сильно повышает конверсию для репетиторов, мастеров красоты, ремонтников.

### 9. Статистика для мастера в кабинете

**Воронка:** просмотры профиля → клики на услугу → запросы контакта → встречи → заказы → отзывы. Эталон: Avito Pro и YouDo. Обязательно.

### 10. График работы / availability

**Эталон: Яндекс.** Дни недели + часы работы. Если мастер «не на смене» — не в топе выдачи.

## Anti-patterns — что НЕ повторять

### 1. Паспорт на старте регистрации

❌ Профи.ру требует слишком рано → конверсия падает. **Откладывать на «дозаполните профиль».**

### 2. Pre-moderation после каждого изменения

❌ Яндекс Услуги: 2 дня без видимости после смены цены. **Делать post-moderation** (профиль виден, проверка в фоне), либо мгновенная для крупных правок.

### 3. Шифровать отклики и контакты

❌ Не делать «таинственный лид» где исполнитель не знает что увидит. **Открыто** показывать описание, бюджет, район. Клиент решит, насколько это интересно.

### 4. Бид-аукцион как единственная модель

❌ YouDo: «торгуйтесь за каждый заказ» → неудобно ремонтникам с прайсом. **Прайс-лист первичен, бид — опционально для конкретных категорий** (грузоперевозки).

### 5. Объявления вместо профиля

❌ Авито: каждая услуга = новое объявление + новый таймер. **Один профиль мастера + список его услуг внутри.**

### 6. Эмодзи в категориях / иконках

❌ Avito-style с цветными бейджами и эмодзи. **Lucide / Iconify color-set / SVG** — наша линия (см. CLAUDE.md).

### 7. «Договорная цена» как дефолт

❌ Снижает CTR на 40%+. **Прайс-лист с цифрами обязателен**, договорная — опция.

### 8. Жадная монетизация лидов

❌ YouDo и Профи берут с мастера 30–500 ₽ за каждый отклик, и большая часть — холостая. **Наш USP — мы не берём денег**, поэтому нет искажения.

### 9. Длинная анкета на онбординге

❌ Профи.ру → 20 минут до первой публикации → отказы. **Минимум на старте, остальное в фоне.**

### 10. Скрытие конкурентов / pay-to-top

❌ Avito Pro Max, Яндекс продвижение. Дискриминирует тех, кто не платит. **У нас нет монетизации видимости — этого не должно быть.**

## Рекомендации по применению в xtrud

### 1. Структура master-аккаунта (приоритет 1)

Опираться на **гибрид Яндекс + Профи**:

**Wizard (4 шага, 2 минуты):**
1. Телефон → СМС.
2. Имя + город (Магас / Назрань / Карабулак / другой).
3. **L2 категория** (bottom-sheet с поиском по 64 категориям).
4. Готово → push «Дозаполните профиль».

**Профиль:**
- Аватар (фото) + имя.
- L1/L2/L3 категории (несколько).
- **Прайс-лист услуг** (отдельный экран, bottom-sheet на каждую строку).
- Портфолио 10+ фото.
- Видео-визитка (опционально).
- О себе (текст до 2000 символов).
- Образование/сертификаты (опционально).
- Соцсети (опционально).
- Геолокация + radius.
- График работы.
- Бейджи: телефон/паспорт/самозанятый.

### 2. Категории — bottom-sheet, не chip-row

Использовать **наш CategoryPicker** (если есть) с улучшениями:
- L1 → раскрывается список L2 → раскрывается список L3 (опц.).
- Поиск по всем уровням.
- Множественный выбор (но рекомендация — 1 основная + 2–3 доп.).

### 3. Прайс-лист

**Отдельный экран** «Мои услуги» в master-кабинете:
- Пустое состояние: иллюстрация + CTA «Добавить услугу».
- Каждая строка: название (свободный текст или из L3) + цена + единица + описание (опц.) + фото (опц.).
- Bottom-sheet редактирования (как в order-form).

### 4. Категории доверия (бейджи)

В карточке мастера — **3 типа бейджей**:
- Маленькие пилы рядом с именем: ✓ Телефон, ✓ Паспорт, ✓ Самозанятый.
- Hover/tap → объяснение «почему важно».

### 5. Статистика для мастера

В master-кабинете — **виджет с воронкой**:
- Просмотры профиля за неделю.
- Контакты (звонки/сообщения).
- Заказы.
- Средний рейтинг + число отзывов.

### 6. Чат с клиентом

Стандартный паттерн (как у нас уже есть): **внутренний чат** + push-уведомления, поддержка фото и шаблонов. Анти-увод — необязательно (но желательно лёгкое предупреждение «лучше остаться в чате xtrud, мы поможем при споре»).
