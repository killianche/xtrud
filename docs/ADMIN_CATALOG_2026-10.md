# Админка: работа с каталогом (№284, 2026-10-07)

Запрос владельца: «добавлять, удалять, менять категории и подкатегории,
переносить задания из категории в категорию — супер удобно».

## 1. Что есть сейчас

Экран «Каталог» в веб-админке (`admin/src/pages/Catalog.tsx`):
- список подкатегорий по разделам;
- переключатели «показывать / скрыть» и «откликается любой / только
  специалист»;
- счётчики открытых заданий и специалистов.

Создать подкатегорию можно только с экрана «Без категории». Назначить
категорию можно только одному заданию оттуда же.

Нет:
- переименования и смены иконки;
- переноса подкатегории в другой раздел;
- синонимов поиска;
- удаления или слияния;
- порядка следования;
- просмотра заданий в категории и массового переноса.

Разделы верхнего уровня (12) зашиты в приложение (`src/lib/product-scope.ts`,
иконки `assets/images/sections/`). Новый раздел без сборки приложения
появиться не может: здесь его можно переименовать и переставить, а
добавление нового — через сборку.

## 2. Референсы

- **Настройки iOS и «Файлы» macOS**: список слева, подробности справа; правка
  на месте, подтверждение только для необратимого.
- **Shopify и WooCommerce, «Коллекции и категории»** — `UNKNOWN`, по памяти:
  - правка в боковой панели;
  - массовые действия над отмеченными строками;
  - «удаление» с переносом содержимого в другую категорию.

## 3. Решение

**Раскладка: два столбца.**
- **Слева — разделы.** Название, число подкатегорий и заданий; переименование
  на месте; стрелки «выше / ниже».
- **Справа — подкатегории выбранного раздела.** Карточкой каждая: имя,
  иконка, счётчики (открытые задания, специалисты), переключатели видимости и
  откликов, стрелки порядка.
- **Над правым столбцом — поиск по всем подкатегориям.**

**Карточка подкатегории раскрывается панелью правки:**
- название;
- иконка — сетка из белого списка;
- раздел — список;
- синонимы поиска — «чипы» с добавлением и удалением.

Сохранение — одной кнопкой. Журнал действий админа пишется, как у
остальных admin-RPC.

**«Удалить» = «Слить в…».** Всегда выбирается подкатегория, куда переходят:
- задания (все, включая закрытые — история не теряется);
- категории специалистов (без дублей);
- синонимы.

Сама подкатегория выключается (is_active = false), строка остаётся ради
истории. Перед подтверждением показывается, сколько заданий и специалистов
перейдёт.

**«Задания в категории».** Список с отметками и кнопкой «Перенести в…». При
переносе открытого задания специалистам новой категории уходит рассылка, как
при назначении из «Без категории».

**Новая подкатегория** — кнопка в каждом разделе. Ту же функцию
(`admin_create_category`) используют «Без категории» и помощник-нейросеть.

**Отвергнуто:**
- **Таблица со всеми полями в строку.** Не помещается, правка в ячейках
  неудобна.
- **Удаление без переноса.** Задания и специалисты остались бы без категории.

## 4. Доступ

Всё через admin-RPC с проверкой `is_admin_session()` и записью в журнал
`admin_actions`. Миграция 0238 проходит проверку роли безопасности.
