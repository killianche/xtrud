# Админка xtrud — редизайн (2026-10-04)

> DECISION владельца 2026-10-04 (очередь №194): «сделай сайт-админку для
> нас… супер удобный, как программа для клиентов… классный UX/UI и хороший
> дизайн… полностью управлять xtrud через админку».
> Контракт и границы доступа — [`ADMIN_PANEL.md`](ADMIN_PANEL.md), он не
> меняется: тонкий клиент без секретов, вся власть в функциях `admin_*`,
> каждое действие — в журнал.

## 1. Разбор того, что есть (снимки на выдуманных данных, `scripts/screenshots/admin-shot.mjs`)

- **Навигация** — 9 пунктов в одну строку сверху. На телефоне строка
  обрезается («Пасп…»), сгруппировать нечего, у очередей нет счётчиков —
  чтобы узнать, есть ли новые жалобы, нужно зайти в каждый раздел.
- **«Обзор»** — 8 голых чисел без динамики и без ответа на главный вопрос
  «что мне сейчас сделать». Очереди (жалобы, паспорта, заявки на звонок,
  специалисты на проверке) не видны.
- **Нет разделов** «Задания», «Отзывы», «Каталог». Задание можно скрыть только
  из жалобы, найти задание по названию нельзя, отзыв скрыть нельзя, категории
  не управляются. «Полностью управлять» сегодня невозможно.
- **Нет общего поиска** — человека по номеру ищут, только зайдя в «Люди».
- **Мелочи:** статус `banned` не переведён; таблица на телефоне уезжает
  вбок; даты с точностью до минуты там, где важно «2 часа назад»; после
  действия нет подтверждения (тоста) — непонятно, сработало ли.

## 2. Референсы

| Источник | Что берём | Почему |
|---|---|---|
| Vercel Dashboard / Geist (образец владельца для админки, 2026-09-03) | Визуальный язык: почти белый лист, чернила, линия 1px вместо тени, моноширинные цифры | Решение владельца уже принято; меняем каркас и удобство, не стиль |
| Linear | Боковая панель с группами и счётчиками, «⌘K» — поиск и переход куда угодно, отклик без перезагрузки | Админка — рабочий инструмент на каждый день: главное — дойти до дела в один шаг |
| Stripe Dashboard | Карточка объекта как отдельная страница со всеми связями (человек → его задания → отклики), статусы-бейджи, относительное время с точным в подсказке | Модерация решается по контексту, а не по id |
| Shopify Admin (веб и мобильное приложение) | Та же админка на телефоне: таблица превращается в список карточек, меню — в выезжающую панель | Владелец часто на телефоне: push «заявка на звонок» → открыть → позвонить |
| iOS (Настройки, Почта) | Группированные списки, понятные пустые состояния, подтверждение опасных действий | Привычные паттерны; админка — «программа», а не страница |

`UNKNOWN`: внутреннее устройство чужих админок не изучалось — берём только
видимые паттерны.

## 3. Варианты

- **A. Доделать точечно** — оставить верхнее меню, добавить разделы. Дёшево,
  но меню уже не помещается, а без «Требует внимания» и поиска удобнее не
  станет. Отвергнут.
- **B. Новый каркас (выбран)** — боковая панель с группами и счётчиками,
  «Обзор» = «Требует внимания» + динамика, общий поиск ⌘K, новые разделы
  «Задания», «Отзывы», «Каталог», тосты, относительное время, тёмная тема,
  телефон. Цена: ~1 день фронтенда + миграция 0215 (только новые функции
  чтения/действий, существующее не меняется).

## 4. Структура (вариант B)

```
Обзор                 — «Требует внимания» (очереди со счётчиками), цифры с
                        динамикой за 30 дней, последние действия журнала
ПЛОЩАДКА   Люди       — список, поиск; карточка: профиль, задания, отклики,
                        отзывы, действия (санкции, пароль, номер)
           Специалисты— каталог, скрыть/показать
           Задания    — НОВОЕ: список по статусу, поиск; карточка: описание,
                        фото, клиент, отклики, исполнитель; скрыть / вернуть
           Отзывы     — НОВОЕ: список, скрыть / вернуть
МОДЕРАЦИЯ  Жалобы [n] · Паспорта [n] · Восстановление [n]
КОНТЕНТ    Каталог    — НОВОЕ: разделы и подразделы, показать / скрыть
           Реклама    — баннеры Главной
СИСТЕМА    Настройки · Журнал
```

Телефон: вместо панели — шапка с названием раздела, поиском и кнопкой меню
(панель выезжает слева); таблицы — списком карточек.

## 5. База (0215, только новое)

- `admin_attention()` — счётчики очередей одним запросом.
- `admin_metrics_series(p_days)` — по дням: регистрации, задания, отклики.
- `admin_list_orders(p_search, p_status, p_limit, p_offset)`,
  `admin_order_card(p_order_id)`, `admin_restore_order(p_order_id, p_reason)`
  (вернуть задание, скрытое модерацией).
- `admin_list_reviews(p_status, p_limit, p_offset)`,
  `admin_set_review_status(p_review_id, p_status, p_reason)`.
- `admin_list_categories()`, `admin_set_category_visible(p_l2_id, p_visible, p_reason)`.
- Все — `is_admin_session()`, `SECURITY DEFINER`, фиксированный
  `search_path`, действия — в `admin_actions`.

## 6. Не строим

- Финансы, арбитраж, правку чужого текста — по `ADMIN_PANEL.md` §4.
- Массовую рассылку push всем пользователям — вопрос владельцу (риск спама и
  отписок; в «Настройках» её нет, пока владелец не скажет).
- Список L1 (разделов верхнего уровня) — это состав релиза приложения
  (`src/lib/product-scope.ts`); в «Каталоге» управляются подразделы.
