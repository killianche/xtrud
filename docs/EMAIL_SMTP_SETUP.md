# Письма для сброса пароля — подключение почтового сервиса (простыми словами)

> Зачем: восстановление пароля работает через письмо на почту. Встроенная почта
> Supabase отправляет всего ~2–3 письма в час — этого хватает только на тесты.
> Чтобы письма доходили всем пользователям, нужно один раз подключить почтовый
> сервис. **Регистрацию и вход это НЕ затрагивает** — они работают без писем.

## Что выбрать

Рекомендую **Resend** — бесплатно 3000 писем в месяц (100 в день), проще всех
настраивается. Альтернативы: SendGrid, Amazon SES, Mailgun — подойдёт любой.

## Шаги (≈10 минут)

### 1. Завести аккаунт Resend
- Зайти на https://resend.com → Sign up (можно через Google).
- Это бесплатно, карта не нужна.

### 2. Подтвердить домен `xtrud.pro` (чтобы письма не падали в спам)
- В Resend: **Domains → Add Domain → `xtrud.pro`**.
- Resend покажет несколько записей (DKIM/SPF) — их нужно добавить в настройках
  домена `xtrud.pro` (там же, где настраивали сайт). Это как «подтвердить, что
  домен ваш». После добавления нажать **Verify** — станет зелёным.
- *(Можно временно пропустить и слать с тестового адреса Resend, но тогда письма
  чаще летят в спам — лучше подтвердить домен сразу.)*

### 3. Получить ключ (API key) и данные SMTP
- В Resend: **API Keys → Create API Key** → скопировать ключ (начинается с `re_...`).
- Для Supabase нужны SMTP-данные Resend (раздел **SMTP** в Resend):
  - Host: `smtp.resend.com`
  - Port: `465` (или `587`)
  - User: `resend`
  - Password: ваш API key (`re_...`)

### 4. Прописать в Supabase
- Supabase → проект xtrud → **Authentication → Emails → SMTP Settings** (или
  Project Settings → Auth → SMTP).
- Включить **Custom SMTP** и заполнить:
  - **Sender email:** `noreply@xtrud.pro` (или `support@xtrud.pro`)
  - **Sender name:** `xtrud`
  - **Host:** `smtp.resend.com`
  - **Port:** `465`
  - **Username:** `resend`
  - **Password:** ваш ключ `re_...`
- Сохранить.

### 5. Проверить
- На сайте: экран входа → «Забыли пароль» → ввести реальную свою почту →
  должно прийти письмо со ссылкой → по ней задать новый пароль.

## Если хотите, чтобы доделал я

Мне для этого нужен от вас **API key Resend** (`re_...`) и подтверждённый домен
(шаги 1–3). После этого я пропишу SMTP в Supabase и проверю отправку. Ключ можно
прислать — я положу его только в настройки Supabase, в код он не попадёт.

## Текст письма (необязательно, но желательно)
Шаблон письма сброса пароля в Supabase → Authentication → Emails → «Reset Password».
Можно перевести на русский и поставить ссылку на `xtrud.pro/reset-password`. Сделаю
по запросу.
