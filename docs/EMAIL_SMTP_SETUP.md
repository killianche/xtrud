# Письма для сброса пароля — подключение почтового сервиса (для России)

> Зачем: восстановление пароля работает через письмо на почту. Встроенная почта
> Supabase отправляет всего ~2–3 письма в час — этого хватает только на тесты.
> Чтобы письма доходили всем пользователям, нужно один раз подключить почтовый
> сервис. **Регистрацию и вход это НЕ затрагивает** — они работают без писем.

## Что выбрать (для России)

Пользователи в Ингушетии → почты в основном mail.ru, yandex.ru, gmail. Лучше
российский отправитель — оплата в рублях, без санкционных рисков, и до российских
ящиков письма доходят надёжнее.

| Сервис | Кому | Плюсы |
|---|---|---|
| **Яндекс** (рекомендую) | старт | бесплатно для обычного ящика, ~500 писем/день, отлично доходит до РФ-ящиков, можно на домен `xtrud.pro` через Яндекс 360 |
| **Mail.ru** | старт | то же, российский |
| **Unisender / Mailopost / SMTP.bz** | рост | российские сервисы транзакционных писем, рубли, больший объём |
| ~~Resend / SendGrid~~ | НЕ для РФ | доставляют, но это США → регистрация/оплата из России может быть ограничена |

Для сброса пароля объём крошечный (одно письмо на запрос) — **Яндекса хватит**.

## Вариант А — Яндекс (проще всего, ~10 минут)

### 1. Завести/выбрать почту-отправитель
- Подойдёт обычный ящик Яндекса (например, `xtrud@yandex.ru`) — заведите новый
  под проект, чтобы не мешать с личным.
- *(Можно красивее: подключить домен `xtrud.pro` к **Яндекс 360 для бизнеса** —
  тогда отправитель будет `noreply@xtrud.pro`. Это чуть дольше, можно сделать
  позже.)*

### 2. Включить отправку (SMTP) и создать «пароль приложения»
- Яндекс ID → **Безопасность → Пароли приложений** → создать пароль для «Почты».
  Это отдельный пароль именно для отправки (обычный пароль от почты для SMTP не
  подойдёт — так у Яндекса безопаснее).
- В настройках Почты убедиться, что включён доступ по протоколу **IMAP/SMTP**.

### 3. Прописать в Supabase
- Supabase → проект xtrud → **Authentication → Emails → SMTP Settings**
  (или Project Settings → Auth → SMTP) → включить **Custom SMTP**:
  - **Sender email:** ваш ящик, напр. `xtrud@yandex.ru` (или `noreply@xtrud.pro`)
  - **Sender name:** `xtrud`
  - **Host:** `smtp.yandex.ru`
  - **Port:** `465`
  - **Username:** полный адрес ящика (`xtrud@yandex.ru`)
  - **Password:** «пароль приложения» из шага 2
- Сохранить.

### 4. Проверить
- На сайте: вход → «Забыли пароль» → ввести свою реальную почту → должно прийти
  письмо со ссылкой → по ней задать новый пароль.

## Вариант Б — Mail.ru
То же самое, но: **Host:** `smtp.mail.ru`, **Port:** `465`, Username — полный
адрес `@mail.ru`, Password — пароль для внешних приложений (создаётся в настройках
безопасности Mail.ru аналогично Яндексу).

## Если хотите, чтобы доделал я
Пришлите мне **адрес ящика** и **пароль приложения** (Яндекс/Mail.ru) — я пропишу
SMTP в Supabase и проверю отправку. Пароль положу только в настройки Supabase, в
код он не попадёт.

## Текст письма (по желанию)
Шаблон письма сброса в Supabase → Authentication → Emails → «Reset Password».
Переведу на русский и поставлю ссылку на `xtrud.pro/reset-password` по запросу.
