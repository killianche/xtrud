# Контакты в отклике (№322, 2026-10-08)

Запрос владельца: «каждый раз вводить телефон неудобно; человек может
хотеть, чтобы ему писали в WhatsApp, а не звонили; вписал номер один раз —
второй раз он должен появиться сам, „Изменить“ — если нужно».

## 1. Что было (FACT, база и код 2026-10-08)

- Форма отклика подставляла только `users.contact_phone` — он заполнен у
  3 из 12 активных пользователей. У остальных поле было пустым каждый раз.
- Номер из отклика нигде не запоминался.
- Телефон был обязателен в форме, хотя база с 0146 допускает отклик только
  с WhatsApp (`order_responses_contact_required`: телефон ИЛИ WhatsApp).
- Номер отклика видят только автор задания и сам специалист
  (RLS `order_responses_read_participants`). `users.contact_phone` виден в
  каталоге всем — это «открытый номер специалиста» (№302).

## 2. Референсы

- iOS (Apple Pay, App Store): известные данные показаны строкой с
  «Изменить», а не пустым полем. Выбор «как связаться» — переключателями.
- Авито: способ связи «звонки / сообщения» выбирается в объявлении
  (UNKNOWN в деталях).
- Profi.ru, YouDo: контакты исполнителя берутся из профиля, в отклике не
  вводятся (UNKNOWN в деталях).

## 3. Решение

- Номер подставляется сам: прошлый отклик → «Я специалист → Контакты» →
  номер входа (подтверждён звонком при регистрации).
- Блок «Связь с вами»: строка с номером и «Изменить», переключатели
  «Звонки» и «WhatsApp». Можно оставить один; оба выключить нельзя
  (кнопка неактивна, внизу — объяснение).
- Отдельный номер для WhatsApp — поле «Другой номер для WhatsApp» в режиме
  «Изменить».
- «Запоминание» — по прошлому отклику, без новой таблицы и без миграции.

Отвергнуто:
- записывать номер из отклика в профиль (`users.contact_phone`) — он
  виден в каталоге всем; человек, ответивший на одно задание, не соглашался
  показывать номер всем;
- отдельная настройка «мои контакты для откликов» — лишний экран: прошлый
  отклик уже хранит ответ человека.
