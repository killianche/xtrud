# Кто может откликнуться на задание (2026-10-04, №203)

> Владелец: «будучи специалистом без категорий, я мог откликнуться. Простые
> категории (разнорабочий, уборка) — пусть любой; плитка — только с профилем
> специалиста. Найди правильное решение, проверь альтернативы, реализуй».

## Было (FACT)

Откликнуться мог любой вошедший: приложение и база категории специалиста не
проверяли. Профиль специалиста есть у каждого аккаунта (0186), категорий в
нём может не быть (у 8 из 12 профилей их нет).

## Как делают другие

- Profi.ru, Thumbtack, TaskRabbit: исполнитель откликается только на заказы
  в услугах, выбранных в профиле (`UNKNOWN`: точные правила исключений).
- Простые поручения (уборка, грузчики) там тоже обычно требуют выбрать
  категорию — но для небольшой площадки это лишний барьер на старте.

## Варианты

| Вариант | Плюс | Минус |
|---|---|---|
| A. Все категории — только с категорией в профиле | Строго, просто объяснить | Для «разнорабочих» и уборки — лишний шаг, меньше откликов |
| **B. Флаг у подкатегории: открытые — любой, остальные — с категорией (выбран)** | Предложение владельца; гибко, меняется в админке | Нужно решить список открытых |
| C. Без ограничений, только подсказка | Ноль барьеров | Задача владельца не решается |

## Решение (B)

- `categories_l2.open_responses` — откликается любой вошедший. Сначала
  открыты: разнорабочие, клининг, уборка после ремонта, помощь по хозяйству,
  сад и участок, вывоз мусора, грузчики и переезды, доставка (3 вида),
  промоутеры, обзвон и переписка, поиск информации. Остальное меняется в
  админке («Каталог» → «Отклик: любой / специалисты»).
- Остальные — нужна категория задания (основная или дополнительная) в
  профиле специалиста.
- Приложение спрашивает заранее (`can_respond_to_order`): «Нужна категория
  „Плитка и мозаика“» — системное окно iOS с кнопкой «Добавить категорию» →
  экран «Чем занимаетесь» с уже отмеченной категорией → «Готово» → назад к
  заданию.
- База отказывает и сама (триггер на отклик и повторный отклик): старые
  сборки получают понятный текст, правило не обходится.
- Лента заданий не меняется: специалист видит все задания и может добавить
  категорию прямо из задания.

## Обязательный вход (№202, в той же миграции)

Флаг `require_login`: приложение сразу показывает «Ваш номер» → пароль (если
аккаунт есть) или регистрацию (если нет). App Review 5.1.1(v) разрешает вход,
если у приложения существенные функции на аккаунте (публикация, отклики,
контакты) — это так; тестовые аккаунты для проверки в App Store Connect
указаны (FACT, read-only проверка 2026-10-04). Если проверка всё же попросит
доступ без входа — выключатель в админке («Настройки» → «Вход в
приложение»), без новой сборки.
