# Доверие к специалисту: подтверждение компании и опыта (предложение, 2026-10-04)

> Запрос владельца 2026-10-04 (очередь №196): подтверждать не только личность,
> но и компанию; подтверждать опыт (10+, 20+ выполненных работ) после звонка
> и показа работ; значки рядом с именем и опытом; выделить качественного
> мастера среди новичков. Статус: **предложение, ждёт решения владельца.**

## 1. Что есть сейчас (FACT, база 2026-10-04)

- Подтверждение личности — паспорт + имя с документа (`master_verifications`,
  0174/0182). Значок `VerifiedBadge` у имени, если `verification_level ≥ 2`.
  Заявок — 1, одобренных — 0.
- В профиле специалиста уже есть поля компании: `account_type`
  (solo / brigade / company), `legal_name`, `inn`, `ogrn`, `tax_status`. Все
  12 специалистов — `solo`.
- `experience_years` — опыт со слов самого человека, никем не проверен.
- `closed_deals` — выполненные через xtrud задания (считает база). Сейчас
  у 3 специалистов, максимум 2.
- Рейтинг и отзывы — только по реальным заданиям.

## 2. Главный принцип

Значок обещает проверенный факт (design-quality §5). Поэтому три разных
сигнала нельзя смешивать в одну «галочку» — у каждого свой источник:

| Сигнал | Кто подтверждает | Насколько надёжно |
|---|---|---|
| Это реальный человек / реальная компания | Документ, проверка админом | Высоко |
| Есть опыт вне xtrud | Админ по фото работ и звонкам клиентам | Средне — зависит от проверки |
| Работает хорошо именно здесь | База: выполненные задания, рейтинг, отказы | Высоко и честно — автоматически |

## 3. Предложение

### 3.1. Значок у имени — «Личность подтверждена» / «Компания подтверждена»

- Один значок у имени, разный текст по типу аккаунта: частный — «Паспорт
  проверен», компания — «Компания проверена» + юрлицо в профиле.
- Компания: ИНН/ОГРН → админ сверяет по ЕГРЮЛ (бесплатно, egrul.nalog.ru) +
  документ, что человек представляет компанию (директор по выписке или
  доверенность). Самозанятый — проверка статуса НПД по ИНН (сервис ФНС).
- Автоматическая проверка ИНН через API (DaData и аналоги) — позже; на
  нынешних объёмах админ справится руками. `UNKNOWN`: условия бесплатного
  тарифа DaData не проверены.

### 3.2. «Опыт подтверждён» — отдельная строка в блоке «Опыт», не у имени

- Уровни: **10+, 30+, 100+ объектов** (вместо 10/20: разница 10 и 20 для
  клиента незаметна, а уровни должны различаться заметно). Решать владельцу.
- Как проверяем (заявка из профиля специалиста → очередь в админке):
  1. фото работ — не меньше N объектов, у каждого 2–3 фото «до/после»;
  2. 2–3 контакта прошлых клиентов — админ перезванивает;
  3. звонок специалисту.
- Подтверждение действует **1 год**, потом перепроверка — иначе значок
  устаревает.
- Проверенные фото работ получают пометку «работа подтверждена» в портфолио.

### 3.3. Автоматический знак качества — «Надёжный специалист» (альтернатива, которую стоит добавить)

Самый честный способ отделить хорошего мастера от новичка — не ручная
проверка, а измеренное поведение на площадке. Так делают Airbnb («Суперхозяин»)
и Thumbtack («Top Pro»): знак выдаётся по цифрам и снимается сам.
Пример критериев для xtrud (подобрать по данным, когда их станет больше):

- ≥ 5 выполненных через xtrud заданий;
- рейтинг ≥ 4,7;
- нет отменённых по вине специалиста за 90 дней;
- отвечает на отклик / сообщения в среднем быстрее X часов (`UNKNOWN`:
  время ответа сейчас не измеряется).

Сейчас никто из специалистов критериям не соответствует (максимум 2 сделки),
поэтому это этап «когда наберётся база», но заложить стоит сразу.

### 3.4. Новички — не наказывать

- Для нового специалиста — нейтральная пометка «Новый на xtrud», а не
  пустота: клиент понимает, почему нет отзывов.
- Порядок в каталоге: проверенные и «Надёжные» выше, но новички не
  исчезают (иначе им не получить первые заказы, и площадка опустеет).

## 4. Что увидит клиент (карточка специалиста)

```
Адам Евлоев  ✓            ← значок: «Паспорт проверен» / «Компания проверена»
★ 4,9 · 12 отзывов · 15 заданий в xtrud
Опыт: 8 лет · Опыт подтверждён xtrud — 30+ объектов
```

Не больше двух значков у имени — иначе они перестают что-то значить.

## 5. Цена реализации (оценка)

| Часть | Объём |
|---|---|
| Компания: тип проверки в `master_verifications`, экран подачи (ИНН + документ), очередь в админке, текст значка | ~1 день |
| Опыт: таблица заявок, экран подачи (фото + контакты), очередь в админке, строка в профиле, срок действия | ~2 дня |
| «Надёжный специалист»: функция расчёта по расписанию + значок | ~1 день, когда будет база |
| Каталог: фильтр «Только проверенные», порядок | ~0,5 дня |

Очереди проверки встают в новую админку (раздел «Проверки»: личность,
компания, опыт).

## 6. Решения владельца
