🏆 Топ-функции, которые стоит применить
Карточка мастера (главный экран продукта)
Берём у Thumbtack pro detail page:

Большое hero-фото 16:9 вверху (а не аватарка 96×96, как сейчас) — у нас принцип «фото — главный визуальный нерв», но мы его не реализуем.
Sticky bottom-bar «Написать в чат» — всегда видна при скролле. У TaskRabbit Tasker card такая же.
Блочная вёрстка trust-signals: рейтинг → «выполнено N работ» → FAQ от мастера → фото-галерея портфолио. Сейчас у нас всё это есть в коде, но разложено в плоский список вниз пятым блоком.
Лента мастеров в категории
Берём у TaskRabbit Browse Taskers:

Карточка = фото работ (3-4 превью) + аватар + имя + рейтинг + hourly rate + «выполнено N задач». У нас сейчас 48-pixel аватар без фото работ.
Услуги-как-прайс → перенести в chip-фильтры под мастеров, а не над, как сейчас (паттерн Profi.ru каталога).
OTP-экран
Берём у Zoox, Opal, Capital One (индустрия-стандарт 2026):

6 раздельных боксов для OTP вместо одного TextInput. Auto-paste из SMS. Auto-focus следующего бокса.
Убрать «Sprint 1: код принимается любой» — это disclaimer разработчика, виден пользователю прямо на первом экране после телефона.
Заказы — статусы
Берём у Profi.ru «Мои заказы»:

OrderStatusBadge компонент с цветными pill-плашками на всех 6 статусах state-machine (open / assigned / in_progress / completed / cancelled / expired). Сейчас статус читается только через косвенные подсказки в тексте.
Кнопка «Отменить заказ» через kebab-меню + bottom-sheet confirm. BD-уровень уже поддерживает T2/T6 переходы, UI-выхода нет.
Создание заказа
Берём у TaskRabbit request flow + Profi.ru «специалисты напишут сами»:

Wizard в 3 шага с progress-indicator вместо одного скролла на 6 секций.
Trust-сигнал «обычно отвечают за 30 минут» на submit-экране — у TaskRabbit это поднимает конверсию заметно.
Submitted-экран с «что дальше» вместо router.back() в никуда.
Чат
Берём у Airbnb messaging + Thumbtack chat:

Шаблоны быстрых ответов («Когда удобно?», «Сколько будет стоить?», «Я подъеду через 30 мин») — самый высокий ROI в marketplace-чате. Особенно для мастеров на выезде.
Контекст заказа в шапке чата: статус, бюджет, дедлайн. У нас данные уже идут в payload useMyChats, UI их игнорирует.
Date-separator, group-by-sender, статусы прочтения, typing-indicator, аватары в треде — базовая гигиена мессенджера.
На десктопе берём Slack split-layout: слева список диалогов, справа активный.
Профиль мастера
Берём у Airbnb host:

Режим «Посмотреть как клиент» — переключатель на верху profile/index.tsx. Сейчас мастер не видит, как выглядит его публичная карточка.
Разделение «showcase» (что видят другие) и «settings» (мои настройки) — два разных режима в одном табе.
Портфолио-upload
Берём у Photoroom + Airbnb host upload:

Crop с фиксированным aspect-ratio 4:3 (или 16:9) при выборе фото. expo-image-picker поддерживает allowsEditing: true, aspect: [4, 3].
Минимальное разрешение 1200×900, иначе предупреждение «фото будет выглядеть мутно».
Tile-skeleton при загрузке нескольких фото подряд.
Радиус выезда
Берём у Яндекс.Услуги + Craigslist radius map:

Слайдер 5-50 км + мини-карта с radius-circle вместо голого number-pad. Сразу понятно, насколько большой охват.
Theme-toggle
Берём у BuzzFeed + Overcast:

На mobile: bottom-sheet «Match System / Light / Dark» (radio-list с checkmark).
На web: видимая иконка Sun/Moon в шапке (паттерн Cal.com).
🛠 Системные фичи для design-system (не визуал, а инфраструктура)
Это то, чего у нас в коде ещё нет, но без чего «качественный» продукт не получится:

useThemeColor(token) хук — у нас в colors.ts уже полная dark-палитра, но компоненты к ней не подключены, хардкодят hex прямо в color="#0a0a0a". Решается одним рефакторингом.
Skeleton-loaders — <Skeleton variant="text|circle|rect"> + 4 composable шаблона (MasterCardSkeleton, OrderRowSkeleton, etc.). Сейчас 46 мест с ActivityIndicator — это «дёшево» и нарушает Cal.com-эстетику. Реф: Cal.com booking, Linear issues.
<EmptyState> единый компонент с иконкой + hint + CTA. Notion/Linear pattern. У нас каждая группа делает свой empty state, и часто без CTA — это тупик для пользователя.
<Toast> единый вместо Alert.alert("Готово"). Linear-стайл: «Заказ создан • Отменить» внизу 3 секунды.
expo-image с blurhash + transition вместо RN Image. У Airbnb, Thumbtack — все фото загружаются progressively.
Cal Sans display-шрифт — DESIGN.md его прописывает, в _layout.tsx подгружается только Inter. 10 минут работы, заметный эффект на заголовки.
🎁 Неожиданно хорошие референсы
То, что агенты нашли в Lazyweb и я бы не подумал гуглить:

DoorDash chat-in-order — чат не отдельный таб, а вшит внутрь карточки заказа. Если в нашем продукте core-loop = «заказ → диалог → выполнение», возможно стоит подумать в эту сторону (но это серьёзное архитектурное решение, не делать без обсуждения).
Overcast accent-picker — отдельные accent-цвета для light и dark. Современный паттерн, можно добавить в Sprint 27+ как «настройка для тех, кому интересно».
Wise/Botim onboarding — disclaimer Terms/Privacy не в виде «Sprint 1...», а как нейтральная ссылка под кнопкой submit. Образец как закрыть юридический момент элегантно.
Notion mobile sidebar overlay — для будущего hamburger-menu на mobile-web, если когда-то понадобится.
