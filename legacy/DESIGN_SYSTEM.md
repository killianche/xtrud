## 1. Философия

Чистый современный SaaS-минимализм в духе **Cal.com / Linear / Vercel / Stripe**. Без декоративных, национальных, "тёплых" элементов. Дизайн читается как профессиональный продукт мирового уровня, а не как региональное приложение.

Воздух, дисциплина типографики, монохром + сдержанный синий акцент, hairline-бордеры, soft-shadow. Контент берёт на себя всю визуальную яркость — это значит: **категории, портфолио мастеров и фото работ должны быть атмосферными, дорогими, профессиональными.** Дизайн системы их обрамляет, а не перебивает.

---

## 2. Темы

Сразу две темы — **Light** и **Dark**. Переключаются:
- автоматически по системной настройке (`useColorScheme`)
- вручную через свитчер в настройках пользователя
- сохраняется выбор в `AsyncStorage` / `localStorage`

Light — дефолт для новых пользователей. Web SSR должен правильно резолвить тему без "flash of wrong theme" (см. CROSS_PLATFORM_RULES.md).

## 4. Типографика

### 4.1. Шрифты

- **Display + body:** [Inter](https://rsms.me/inter/) — единственный системный шрифт. Грузится через `expo-font` из пакета `@expo-google-fonts/inter`.
- **Альтернатива для display:** Manrope weight 700 (если захочется чуть больше геометричности заголовков). Один из двух — выбираем после первого прототипа.
- **Моноширинный:** JetBrains Mono — для кода, инвойсов, чисел в инвойсах.
- **Fallback стек:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`.

**Никакого Cal Sans** — лицензированный, использовать нельзя.

### 4.2. Шкала (в `dp` — работает одинаково на iOS / Android / web)

| Токен | Размер | Weight | Line height | Tracking | Использование |
|---|---|---|---|---|---|
| `display-xl` | 56 | 700 | 1.05 | -2 | Hero h1 на landing |
| `display-lg` | 44 | 700 | 1.1 | -1.5 | Section h1 |
| `display-md` | 32 | 700 | 1.15 | -1 | Section h2 |
| `display-sm` | 24 | 600 | 1.2 | -0.5 | Card h3, цены на pricing |
| `title-lg` | 20 | 600 | 1.3 | -0.3 | Названия экранов, имя мастера в карточке |
| `title-md` | 18 | 600 | 1.4 | 0 | Заголовки карточек |
| `title-sm` | 16 | 600 | 1.4 | 0 | Малые заголовки, лейблы форм |
| `body-lg` | 17 | 400 | 1.5 | 0 | Body на mobile (iOS HIG baseline) |
| `body-md` | 16 | 400 | 1.5 | 0 | Body по умолчанию, читабельность |
| `body-sm` | 14 | 400 | 1.5 | 0 | Вторичный текст, footer |
| `caption` | 13 | 500 | 1.4 | 0 | Бейджи, мелкие лейблы |
| `caption-xs` | 12 | 500 | 1.3 | 0 | Tаймстемпы, fine-print |
| `button` | 15 | 600 | 1 | 0 | Лейблы кнопок |
| `nav` | 14 | 500 | 1.4 | 0 | Top-nav, табы |

**Правила:**
- Минимум body — 14 dp. Никогда меньше.
- На mobile body = 17 dp (соответствует iOS HIG), на web body = 16 dp.
- Заголовки 600 или 700, никогда 800/900.
- Negative letter-spacing **только** на display-размерах.

## 7. Тени и elevation

| Уровень | Light theme | Dark theme | Где |
|---|---|---|---|
| flat | нет тени, нет бордера | нет тени, нет бордера | Секции, hero, top-nav |
| hairline | 1px `hairline` | 1px `hairline` | Инпуты, разделители, "тихие" карточки |
| card | нет тени, фон `surface-2` | нет тени, фон `surface-2` | Базовые карточки |
| soft | `0 1px 2px rgba(0,0,0,0.05)` | `0 1px 2px rgba(0,0,0,0.4)` | Pricing, поднятые блоки |
| floating | `0 4px 16px rgba(0,0,0,0.08)` | `0 4px 16px rgba(0,0,0,0.5)` | Dropdown, popover, modal |

**Важно для cross-platform** (см. правила в CROSS_PLATFORM_RULES.md):
- На Android `shadow-*` Tailwind не работает → используем `elevation` через NativeWind plugin
- На web `box-shadow` работает напрямую

## 8. Иконки

**Стандарт системы:** [`lucide-react-native`](https://lucide.dev/).

- Толщина обводки: 1.75 px (между `1.5` хрупким и `2` тяжеловатым)
- Размер иконок в UI: 20 dp базовый, 24 dp для крупных, 16 dp для inline
- Цвет: всегда наследует `currentColor` родителя
- Минимальная зона касания иконки-кнопки: 44 × 44 dp (hitSlop обязателен)

## 9. Ключевые компоненты системы

### 9.1. `category-tile` 🔴 СИГНАТУРНЫЙ

Это **главный визуальный приём** нашей системы, унаследован из предыдущего проекта пользователя. Используется на главной клиента, в каталоге категорий, в выборе категории при создании заказа.

**Анатомия:**
- Тёмная атмосферная фотография на фоне (interior, work-in-progress, готовый результат)
- Чёрный overlay `linear-gradient(to bottom, rgba(0,0,0,0.55), rgba(0,0,0,0.2))` для читаемости текста
- Лейбл категории — белый, `title-lg` или `title-md`, weight 600, top-left
- Padding 16-20 dp от края изображения до текста
- Radius `radius-xl` (20 dp)
- Aspect-ratio варьируется: 1:1 (квадрат), 3:4 (вертикальный), 16:9 (горизонтальный) — для bento-сетки

**Bento layout:**
- Сетка из карточек разного размера и aspect-ratio (как на скриншоте)
- На mobile: 2 колонки, чередование квадрат + квадрат / широкий
- На tablet: 3 колонки
- На desktop: 4 колонки, более выраженный bento (1 широкая на 6 колонок + 6 узких и т.д.)
- Gap между плитками: `space-3` (12 dp) mobile / `space-4` (16 dp) desktop

**Фотография — критически важно:**
- Высокое разрешение (минимум 1200×1200 для квадратных)
- Атмосферное освещение (тёплое тёмное / закатное / профессиональный интерьер)
- Без watermarks, без стоковой "пластиковости"
- Источники: Unsplash (бесплатно), Pexels, либо заказная фотосессия конкретных мастеров
- Преимущественно интерьерная съёмка / результат работы / процесс — НЕ портреты, НЕ продукты на белом фоне

**Состояния:**
- Default: как описано
- Pressed (mobile): scale 0.97 + лёгкое затемнение overlay
- Hover (web only): scale 1.02 + усиленный gradient overlay
- Focused (a11y): 2px ring `accent`

## 11. Tone of voice / копирайт

**Принципы:**
- На "вы".
- Короткие, прямые фразы. Без литературных оборотов.
- Без восклицательных знаков. Никогда. Точка вместо.
- Без "Уважаемые клиенты", "Спешим сообщить", "Поздравляем!".
- Без emoji в системных текстах (можно в чатах пользователей, не в UI).
- Глаголы в действиях: "Найти мастера", "Опубликовать заказ", "Открыть свой номер".
- Лейблы — без точки в конце.

**Примеры:**

| ❌ Плохо | ✅ Хорошо |
|---|---|
| "Нажмите здесь, чтобы опубликовать ваше объявление!" | "Опубликовать заказ" |
| "Поздравляем! Ваш заказ был успешно создан!!!" | "Заказ опубликован. Ждите откликов." |
| "Уважаемый пользователь, мы рады приветствовать вас в нашем сервисе" | "Привет. С чего начнём?" |
| "Введите ваш номер телефона в поле ниже" | "Номер телефона" |

## 12. Логотип — направление (не финал)

Имя проекта: рабочее **xtrud**. Финальное — на твоё усмотрение, возможно ребрендинг.

**Что предлагаю как направление:**
- **Тип:** lowercase wordmark, без декоративных элементов
- **Шрифт:** геометрический sans — кандидаты:
  - Inter Display weight 700 с tracking -2 (наш системный шрифт)
  - Cabinet Grotesk weight 700 (более характерный, бесплатный)
  - General Sans weight 700 (свежий и нейтральный)
- **Возможный mark:** маленькая геометрическая фигура слева от слова — точка, кружок, или абстрактный знак из 2-3 линий. Cal.com делает маленький кружок справа от ".com", Linear использует абстрактный L-mark, Vercel — треугольник.
- **Цвет:** монохром — `ink` на light / `fafafa` на dark. Никаких градиентов, никаких национальных цветов.

**Что НЕ делаем:**
- Не делаем эмблем "молоток + ключ" (банально для мастеровых сервисов)
- Не делаем буквенные монограммы "XT" в квадрате
- Не используем 3D/градиенты/неон
- Не вставляем национальные символы

**Финализация логотипа:** после того как определим финальное имя проекта, можно сделать 3-5 вариантов в Figma и выбрать. Это отдельный шаг.
