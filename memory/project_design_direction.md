Пользователь явно зафиксировал визуальное направление проекта:

**Что делаем:**
- Чистый современный дизайн в духе **Cal.com**, Linear, Vercel, Stripe, Notion.
- Белый/светлый холст, тёмные (почти чёрные) primary CTA.
- Дисциплинированная типографика — Inter / Manrope (Cal Sans использовать нельзя — лицензия).
- Продуктовые UI-фрагменты в маркетинговых блоках вместо иллюстраций.
- Светло-серые карточки (#f5f5f5) + хайрлайн-бордеры.
- Минимализм, монохромная палитра + одна сдержанная акцентная краска.
- Тёмный футер как визуальный финал страницы.

**Что НЕ делаем:**
- Никаких кавказских/мусульманских/национальных визуальных элементов (орнаменты, башни, традиционная символика, зелёный/бордовый "национальный" колорит, восточная каллиграфия).
- Никаких "тёплых аутентичных" пастелей в духе локальных приложений.
- Никаких декоративных иллюстраций "местных мастеров".

**Why:** Пользователь хочет, чтобы продукт читался как современный профессиональный сервис, а не как "региональное приложение". Цель — поднять восприятие сервиса выше визуального уровня Avito и локальных WhatsApp-групп.

**Финальные решения (зафиксировано пользователем):**
- **Темы:** обе — light + dark, переключаемые системно и вручную.
- **Категорийные карточки:** сохраняется паттерн из предыдущего проекта пользователя — bento-grid с тёмными атмосферными фотографиями интерьеров/работ + крупный белый текст-лейбл в левом верхнем углу. Углы ~16-20 dp. Это сильный готовый компонент, остаётся как сигнатурный элемент системы. Документировано в DESIGN_SYSTEM.md.
- **Качество фото:** критично. Не стоковая мелочь — атмосферные, профессионально освещённые, преимущественно "moody" интерьерные кадры (как на скриншоте, который пользователь прислал).
- **Иконки:** Lucide (`lucide-react-native`) — стандарт системы.
- **Акцентный цвет:** сдержанный синий `#3b82f6` для ссылок и selected-состояний, semantic-цвета (success/warning/error) для статусов. Primary action остаётся монохром (#111 на light / #fff на dark).
- **Tone of voice:** короткий, уверенный, без восклицаний. На "вы". Без "Уважаемые клиенты". Эталон — Cal.com / Linear на русском.
- **Логотип:** lowercase wordmark, геометрический sans (Inter Display / Cabinet Grotesk), без декоративных элементов. Финальное имя проекта ещё не утверждено.

**How to apply:**
- При обсуждении любых UI-решений (компоненты, цвета, иллюстрации, логотип) — выбирать вариант ближе к Cal.com / Linear / Vercel эстетике.
- Если предлагаю варианты — все варианты должны оставаться в рамках чистого минимализма. Не предлагать "тёплые" или "национально-окрашенные" альтернативы.
- Функциональные фичи с культурным контекстом (пятничный намаз в календаре, гендерные фильтры, ингушский язык интерфейса) — это **функции**, а не стиль. Они остаются в PROJECT_MAP.md.
- В DESIGN_REFERENCE_CALCOM.md секции "что не брать" (рекомендация тёплой краски, региональных аналогов) — пересмотрены и убраны.
