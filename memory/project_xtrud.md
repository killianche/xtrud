Пользователь проектирует мобильное приложение + сайт ("2 в 1") — бесплатный маркетплейс услуг для Республики Ингушетия. Соединяет мастеров-одиночек, бригады и компании с клиентами.

**Ключевые решения, принятые пользователем:**
- **Монетизация:** только реклама + спонсоры (магазины стройматериалов, банки, страховые). Сервис бесплатен и для мастера, и для клиента.
- **Бюджет:** минимальный, делает "для души".
- **Формат работы:** работаем со мной (Claude) как с нейросетью, составляем концепцию и карту проекта. Код и разработку не делаем — это документ-идея.
- **Приватность клиента:** телефон клиента по умолчанию скрыт. Только сам клиент может позвонить мастеру или открыть свой номер.
- **Конкуренты-референсы:** Profi.ru, Яндекс.Услуги, Thumbtack, TaskRabbit, Armut (Турция), Urban Company (ОАЭ).

**Why:** Регион ~534 тыс. населения, безработица ~24%, ~70-80% жилья — ИЖС. WhatsApp + Telegram доминируют. Тесные тейповые/социальные связи — доверие работает через "сарафан", а не звёзды.

**How to apply:** При работе над концепцией всегда учитывать: культурный контекст (намаз, Рамадан, гендерная чувствительность, поручительства), фокус на стройку/ИЖС/бригады (а не "вкрутить лампочку"), Android-first (85% рынка). Каналы уведомлений: in-app push + Telegram. WhatsApp как канал — НЕ использовать (решение пользователя).
