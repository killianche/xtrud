## Раздел 2. Что нужно реализовать — по важности и интересности

> Две оси: **важность** (от обязательного до nice-to-have) и **интересность** (от рутины до «вау-фишка лидера»). Каждая задача попадает в одну из 4 четвертей.

### Матрица: важность × интересность

```
              ВАЖНОСТЬ →

И     │ ❶ ИНТЕРЕСНО + КРИТИЧНО          ❷ КРИТИЧНО, НО РУТИНА
Н     │ Делаем сразу с двойной отдачей  Делаем потому что блокирует
Т     │                                  
Е     │ • Pre-defined услуги             • Унификация архитектуры цен
Р     │   с placeholder-ценами (P0-4)    • Связь цены с категорией
Е     │ • Bottom-sheet категорий         • Документация и smoke-test
С     │   с поиском (P0-3)               • Управление seed-мастерами
Н     │ • Daily response limit (P0-5)    • Чат — фото проверка
О     │ • UX «удобство мастера»          
С     │   ревизия flow (P0-8)            
Т     │                                  
Ь     │
      │
↓     │ ❸ ИНТЕРЕСНО, НЕ КРИТИЧНО         ❹ НИЗКИЙ ПРИОРИТЕТ
      │ Делаем после P0/P1 для wow       Откладываем
      │                                  
      │ • Видео-визитка                  • Карта PostGIS
      │ • Top-Pro / Local Expert         • Полнотекстовый поиск
      │   gamification бейджи            • Tiered packages
      │ • Дашборд аналитики (P1-1)       • Bio до 2000 символов
      │ • Голосовые в чате (P1-5)        • Госуслуги OAuth
      │ • График работы (P1-2)           • Гарантия xtrud
      │ • Шаблоны ответов (P1-6)         
```

### По уровням важности (с интересностью отмеченной 🌟)

#### 🔴 Уровень 1 — критическая важность (фаза P0, блокеры функциональности)

Без этого master-аккаунт не может считаться готовым. **9 задач, ~4–6 недель работы.**

1. 🌟🌟🌟 **P0-4. Pre-defined услуги (L3) с placeholder-ценами** — главная UX-фича. Мастер выбрал «Сантехника» → видит готовый список «Установка унитаза», «Замена смесителя», «Прочистка засора» из 290 готовых услуг → ставит галочки + свои цены (с подсказкой «обычно берут 1500–3000 ₽»). **Самая интересная фишка плана.**
2. 🌟🌟 **P0-3. Bottom-sheet категорий с поиском** — иерархия L1→L2→L3, search-as-you-type. Эталон Яндекс.Услуги.
3. 🌟🌟 **P0-5. Daily response limit (5 откликов/день)** — как у Яндекса. Защита от спама + готовит инфраструктуру под будущую монетизацию.
4. 🌟🌟 **P0-8. UX «удобство мастера»** — ревизия flow на минимум кликов. Главный экран = заказы, swipe по карточкам, inline-edit, 1-тап действия.
5. 🌟 **P0-1. Унифицировать архитектуру цен** — выбираем `master_services` как single source of truth.
6. 🌟 **P0-2. Связать цену с категорией** — добавить l2_id, l3_id.
7. **P0-10. Цены — режим quote / договорная** — для услуг без фикс-цены.
8. **P0-6. Чат — проверка фото attachments.**
9. **P0-7. Seed-мастера — флаг `is_demo`.**
10. **P0-9. Документация и smoke-test после P0.**

#### 🟡 Уровень 2 — важно для полноценного функционала (фаза P1)

После P0. Не блокирует, но без этих 8 задач мастер недопрофил. **~3–4 недели.**

1. 🌟🌟🌟 **P1-1. Дашборд аналитики мастера** — воронка, профиль views, response time, conversion. **Сильная интересная фича** — мастер видит свою ценность.
2. 🌟🌟 **P1-5. Голосовые сообщения в чате** — норма для РФ-аудитории (WhatsApp), особенно для возрастных мастеров.
3. 🌟🌟 **P1-2. График работы (UI work_schedule)** — мастер выставляет расписание, на карточке бейдж «Доступен сегодня».
4. 🌟 **P1-6. Шаблоны ответов в чате** — 5–10 готовых + свои.
5. 🌟 **P1-3. Service area — multi-city + radius выезда.**
6. **P1-4. Портфолио — проверка/доработка upload.**
7. **P1-7. Самозанятый/ИП UI (без интеграции с ФНС).**
8. **P1-8. Dual-role переключатель — UX-ревизия.**

#### 🟢 Уровень 3 — фичи лидеров для wow-эффекта (фаза P2)

Доводка. Делаем чтобы быть на уровне Яндекс/TaskRabbit. **~3–4 недели.**

1. 🌟🌟🌟 **P2-1. Top-Pro / Local Expert / 5-star Pro бейджи** — gamification без денежного incentive. **Сильная замена платных тарифов.**
2. 🌟🌟🌟 **P2-2. Видео-визитка мастера** — Профи.ру: значительно повышает конверсию для репетиторов и мастеров красоты.
3. 🌟 **P2-3. Расширенные фильтры в каталоге** — рейтинг ≥, опыт ≥, инструмент, верификация.
4. 🌟 **P2-4. Полнотекстовый поиск мастеров.**
5. 🌟🌟 **P2-7. Карта мастеров (PostGIS)** — Yandex Pro pattern, визуально мощно.
6. 🌟🌟 **P2-6. Tiered packages (Basic/Standard/Premium)** — Fiverr pattern, для услуг с уровнями (репетитор, фото).
7. **P2-5. Bio до 2000 символов + языки + sample-preview профиля.**

#### 🕒 Отложено — отдельной фазой «Перед публичным запуском»

Эти 6 задач **обязательны перед открытием для широкой публики**, но не блокируют функциональное доведение в текущей фазе:

1. **Реальный SMS OTP** (SMSC.ru или Тинькофф).
2. **Push-уведомления** (Apple Developer Account + Firebase).
3. **Скрытие телефона до confirmed** (phone masking).
4. **UI верификации мастера** (паспорт + selfie + tax_status загрузка).
5. **Админ-модерация верификации.**
6. **Админ-обработка жалоб + блокировка по номеру.**

#### 🕒 Стратегические v2/v3

«Гарантия xtrud» резервный фонд, виртуальные номера, Госуслуги OAuth, полная интеграция с ФНС, payments через СБП-эквайер.

## Раздел 4. Интересные функции современных компаний — что у нас должно быть

> По каждой платформе — конкретные фичи с короткой пометкой «берём / не берём / адаптируем».

### Из Яндекс.Услуги

| Фича | Берём? | Куда |
|---|---|---|
| **Wizard 4 шага до публикации** (~2 мин) | ✅ Берём | P0-8 (удобство мастера) |

## Раздел 7. Что в результате получит мастер после Фазы 1

1. Регистрация за 2–3 минуты (на demo OTP — настоящий позже).

11. Один тап «Готово» завершает заказ + автозапрос отзыва.
